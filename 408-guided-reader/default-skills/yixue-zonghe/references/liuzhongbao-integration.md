## 五、维护与复现

| 环节 | 脚本（在 `_inbox/刘忠保-生理学/scripts/`） | 说明 |
|------|------|------|
| 音频抓取 | `run_all.py <集号或范围> [--keep-audio]` | 断点续跑、失败重试、自动清理、写台账 |
| 转写 | `transcribe.py` | faster-whisper large-v3；自动注入 CUDA DLL 路径 |
| 术语纠错 | `build_terms.py` + `correct_terms.py` | 三重护栏：虚词黑名单、自洽性校验、上下文护栏 |
| 知识地图 | `build_knowledge_map.py` | 12 章 × 四类信号汇聚 |
| 取证检索 | `search_transcripts.py` | 带时间戳全文检索（`--chapter` / `--ep` / `--context`） |
| 里程碑播报 | `monitor.py` | 每 5 集输出进度并写入 `logs/progress_milestones.md` |
| 装机 | `finalize.py` | 刷新调研文件 → 质检（须 11/11）→ 安装 → 检索接入验证 |

**重新蒸馏**：若转写稿更新（新增集或纠错规则调整），依次执行
`build_knowledge_map.py` → `make_sources.py` → `finalize.py` 即可重建专家库。

**已知局限（必须随引用一并声明）**：
1. 二字词同音未纠（如「续论」应为「绪论」）
2. 夹杂英文术语易被汉语化误识（如 physiology →「非自二者」）
3. 课堂口语存在冗余与重复，提取以语义为准
4. **L3（自我修正）维度素材不足**——全库未见本人明确承认的教学失误，SKILL.md 中已如实标注，不得据此推断
5. 其考点判断依托其熟悉的考纲与院校范围，**不覆盖院校差异化要求**
