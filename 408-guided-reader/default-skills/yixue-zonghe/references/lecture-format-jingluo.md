# 经络腧穴学体例规范

> 本文件为 `yixue-zonghe` 技能功能二"讲义制作"之 **经络腧穴学体例** 规范。
> 覆盖 **十二正经 / 十二经别 / 十五络脉 / 十二经筋 / 奇经八脉** 讲义 及 **腧穴单卡**。
> 经脉讲义蓝本：`references/examples/经络腧穴学-手太阴肺经讲义_OneNote版样板.html`（2026-10-23）。
> 腧穴单卡蓝本：`references/examples/经络腧穴学-太渊(LU9)讲义卡_OneNote版样板.html`（2026-10-23）。

## 〇、全局规定（所有章节适用）

**所有讲义仅产出 OneNote 适配 HTML 成品**，不再额外生成网页底稿（原始含 CSS 的 `.html` 在转换后即丢弃，或直接跳过——直接按 OneNote 兼容结构产出，一步到位）。

产物流水线：
```
生成 OneNote 兼容 HTML  ←  直接按转换后结构产出，或先生成网页底稿再用 to_onenote.py 一步转
    │
    ▼
自检：0 class / 0 CSS 变量 / 0 残留 / 标签平衡
    │
    ▼
交付文件 = 仅 {讲义名}_OneNote版.html 一个
```

**禁止**：同时产出"讲义.html" + "讲义_OneNote版.html"两份。

## 二、四源与专家体系

经络腧穴学体例 **强制四源融合**，缺一不可：

| 层级 | 来源 | 内容 |
|------|------|------|
| **教材基线** | 《经络腧穴学》（第 10 版） | 循行原文、病候分类、腧穴定位主治操作、五输表 |
| **古籍古注** | 《针灸大成》（卷二·十二经病井荥俞经合补虚泻实） | 病候古注、补泻时辰、子母补泻法 |
| **蒸馏倪海厦** | modules/09 十二经腧穴解读 + distilled/02 五输补泻速查 + distilled/04 针灸治症精选 | 腧穴特色主治、扁鹊针法、母穴子穴本穴判定、禁扎警示 |
| **石学敏体系** | SKILL.md 十二经病候新解 + 手法量学总纲 + 《石学敏针灸全集》临床证治 | "是动/所生"现代解读、手法量学参数（1-3min / 6h 效应持续）、临床配穴证治 |

**专家观点标注**：倪师观点用 `.ni` 棕金卡（`#fff8ea` / `#c8940a`）、石师观点用 `.shi` 深蓝卡（`#eaf2ff` / `#1e3a5f`）。所有专家观点与教材观点并列，不替代，标注来源。

## 五、HTML 构件到 OneNote 版的转换约定

| 构件 | 写法 | 说明 |
|------|------|------|
| 侧栏目录（采集） | `<aside class="side">` 内含 `<h2>目 录</h2>` + `<ol><li>...</li></ol>` + `<p class="meta">...</p>` | `to_onenote.py` 从 `class="side"` 采集，脚本只认 class 名不认空属性 |
| 教材基线卡片 | `<div class="card">` | 转成 OneNote 版表格 |
| 倪师卡 | `<div class="ni">` | 转成棕金底卡片，前缀"倪海厦观点" |
| 石师卡 | `<div class="shi">` | 转成浅蓝底卡片，前缀"石学敏观点" |
| 古籍引文 | `<div class="quote">` | 灰色左边框斜体引言 |
| 警示 | `<div class="warn">` | 橙金框警示 |

**禁止**：`side=""`、`meta=""` 等空属性写法，脚本只查 class 名；目录条目用 `<ul>` 脚本不采集，**必须 `<ol>`**。

## 六、十二经差异点（生成时注意）

| 维度 | 肺经（阴金） | 大肠经（阳金） | 备注 |
|------|-------------|---------------|------|
| 五输五行顺序 | 木火土金水 | 金水木火土 | **阴经 vs 阳经相反** |
| 子母补泻 | 母穴太渊（土）、子穴尺泽（水） | 母穴曲池（土）、子穴二间（水） | 阴金/阳金母穴都是土 |
| 时辰 | 寅 3-5 | 卯 5-7 | 肺寅大卯胃辰宫 |
| 多气少血 | 多气少血 | 多气多血 | 倪师 module/09 每条经都有 |
| 经别条数 | 1 条（正） | 1 条 | 每条经都有一条经别 |
| 络脉去向 | 别走阳明（大肠） | 别走太阴（肺） | **互为表里** |
