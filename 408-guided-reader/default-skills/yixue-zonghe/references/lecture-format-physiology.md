# 生理学讲义体例规范（默认输出格式）

> 适用范围：主题为**生理学**的讲义制作（按教材章成章，如细胞的基本功能、血液、血液循环、呼吸、消化、代谢、泌尿、感觉器官、神经系统……）。
> 命中文档的判据见 SKILL.md「功能二 · 讲义体例路由」。
> **本规范为生理学讲义的默认输出格式，无需用户指定。**

---

## 一、体例蓝本（动手前必读）

**蓝本文件**：`references/examples/生理学-细胞的基本功能讲义_OneNote版样板.html`

该文件是一份**完整成品**（《生理学》第 10 版第二章 细胞的基本功能，含物质跨膜转运／信号转导／电活动／肌收缩四节）。
本规范的全部约定都以它为准。**动手写之前先通读蓝本**，逐段对照，确保骨架、栏目、配色、字号一致；
遇到本规范未覆盖的细节，一律以蓝本的实际写法为准。

> 说明：蓝本入库时已按「交付正文不得出现时间戳」的规则清洗——`P## [hh:mm:ss]` 改写为
> 「刘忠保·第 N 讲」可读形式，**无讲次前缀的续段**（如 `刘忠保·第 9 讲 / [00:39:38–00:42:15]`
> 的后半段）一并清除，时间戳专属样式（等宽字体 + 米色底 `#f6e7cd`）与声明该记法的说明句也已去除；
> 其余内容与原文件一致。**新讲义一律照此写法。**

## 二、交付形态

| 项 | 规定 |
|---|---|
| 交付格式 | **OneNote 原生 HTML**（已是导入优化形态，无需再转换） |
| 文件命名 | `<章号>_<章名>_生理学讲义_OneNote版.html`（如 `02_细胞的基本功能_生理学讲义_OneNote版.html`） |
| 导入方式 | OneNote 中「插入 → 文件 → 作为打印输出插入」，或粘贴时选「保留源格式」 |
| 为什么 | 全部内容以表格承载，OneNote 粘贴网页时丢失的浮动/粘性/伪元素/外部样式表在此形态下均不存在，表格结构、底纹与分色标注可完整保留 |

**放弃的写法**：不使用 `div` 布局、不使用 `class` 属性、不使用 CSS 变量、不使用渐变与圆角、
不使用 `position:sticky/fixed`、不使用 `::before/::after`、字号一律 `pt`（不得出现 `px`）。

## 三、整体骨架

```
① 封面表           单格 bgcolor 主色 #143561
② 目录表           目 录 + 说明（教材 / 专家体系 / 素材覆盖）+ 三级条目
③ ［目标］         学习目标与考点边界
④ ［第一节］…［第N节］   正文（按教材小节切分）
⑤ ［速查］         本章速查表 · 思考题
```

**h2 章节标题**统一格式：`［标签］　标题`，其中 `［目标］/［第一节］/［速查］` 为标签位（脚本的 `span.num`），
标签后接全角空格，标题有下划线色条（3px 主色表格）。

**一节一页**：全篇超过约 3 万字时，按节拆成多个 `<章号>_<章名>_<节名>_OneNote版.html`。

## 四、各层栏目与表格 schema

### 4.1 封面表

| 行 | 内容 | 样式 |
|---|---|---|
| 1 | kicker：`PHYSIOLOGY · LECTURE 0N` | 10pt，`letter-spacing:2px`，浅蓝字 |
| 2 | 章名，如「第二章　细胞的基本功能」（章号与章名之间全角空格） | 23pt 白色加粗 |
| 3 | 主题行：本章各节以 ` · ` 连接 | 12.5pt |
| 4 | 来源行三行：`教材基线：`／`专家体系：`／`素材覆盖：` | 9.5pt，标签用 `strong` |

`素材覆盖` 用「第 N–M 讲」可读形式，**不得写 `P02–P10` 或时间戳**。

### 4.2 目录表

表头「目 录」，说明行三行（`《生理学》（第10版）第N章` / `专家体系：…` / `素材覆盖 第 N–M 讲`），
其下为三级条目：`li.grp` 分组 → 一级条目 → `li.l2` 二级条目。

### 4.3 ［目标］学习目标与考点边界

1. `▍考点边界速览` —— 表：`考点 ｜ 要求层次 ｜ 说明`（或按蓝本的卡片形态）
2. **教材基线卡**：本章学习目标（分条列出）
3. **专家卡**：1 行 3 列 —— `专家名 ｜ 一句话定调 ｜ 出处`
4. **专家原话引文块**：白底虚线表格（`border:1px dashed #e8b96a`），`「…」` 用实体字符包整段

### 4.4 ［第一节］…［第N节］正文

| 项 | 规定 |
|---|---|
| 节标题 | `［第N节］　<教材小节名>`（h2） |
| 节内层次 | `▍一、…` → `▍二、…`（h3）；需要时用 h4 `▍（一）…` |
| 每节开头 | 一张「教材基线」卡做本节定位 |
| 机制讲解 | 优先用表格承载（对比、分类、流程、数字清单）；关键数字单列一列 |
| 专家内容 | 每位专家独立卡片；专家原话用白底虚线引文块；标注来源 |
| 易混处 | 加鉴别表或 ⚠️ 提示卡 |

### 4.5 ［速查］本章速查表 · 思考题

| 小节 | 表格 schema |
|---|---|
| `▍速查表 1 · …` | 视内容定列，如 `方式 ｜ 物质 ｜ 结构基础 ｜ 关键数字` |
| `▍速查表 2 · …` | 数字类速查：`项目 ｜ 数值` |
| `▍速查表 3 · …` | 同上 |
| `▍速查表 4 · <专家>口诀汇总` | `口诀 / 提法 ｜ 适用处 ｜ 出处`——出处用「刘忠保·第 N 讲」 |
| 本章小结 | 一段收束性文字（本蓝本用「细胞的四项基本功能」串起全章） |
| `▍章末思考题（教材原题）` | 教材原题逐题列出，可附「提示」 |

> ⚠️ 本类体例**不设**「使用说明」小节（全库统一规定）。专家标注与边界声明改由
> **每张专家卡自身**承担（见第六节），免责句内联到涉治疗与剂量的卡片。

## 六、专家内容标注与边界（必须遵守）

- 本类讲义的专家体系为**仓颉蒸馏专家**（当前为「刘忠保·生理学」），调用规则见
  `references/liuzhongbao-integration.md`。
- 一切观点标注「**蒸馏Skill·刘忠保·基于有限素材**」，与教材观点并列，**不替代教材结论**。
- **出处一律用可读形式**（如「刘忠保·第 2 讲」），**绝不出现时间戳**。
- 「考不考／考到什么层次」类判断必须附**适用边界声明**（本科生／分科生／考研差异）。

  改由**每张专家卡自身**承担（标注来源与边界），免责句内联到涉治疗与剂量的卡片。

## 七、硬性格式规则（质检会逐条查）

1. **不得出现时间戳**：全文不得有 `P## [hh:mm:ss]`、其区间形式（如 `P09 [00:12:28–00:12:45]`）、
   **以及无讲次前缀的续段**——这类最易漏删：
   `刘忠保·第 9 讲 / [00:39:38–00:42:15]` 中的 `[00:39:38–00:42:15]` 同样必须清除。
   也不得用 `P##–P##` 指代素材范围（改写为「第 N–M 讲」）。
   出处一律用可读形式（如「刘忠保·第 13 讲」）。
   `P## [hh:mm:ss]` 这类**记法示例**（解释引用格式时举的反例）也在禁止之列。
   **清洗工具**（底稿或既有讲义含时间戳时，先清洗后交付）：

   ```
   python scripts/strip_timestamps.py --in <讲义>.html --dry-run --check   # 先预演看命中数
   python scripts/strip_timestamps.py --in <讲义>.html --inplace --check   # 确认后原地清洗
   ```

   该脚本兼容三种形态（网页版 `span.ts`、OneNote 版内联样式 span、裸文本），同时清掉删除后
   遗留的多余空白，并会改写「所有引用均带 … 出处」这类随之变成残句的说明文字。**清洗后须复跑一次
   `--check`，残留应为 0**（幂等：已清洁的文件再跑不产生任何改动）。
2. `class="` = 0；`var(--` = 0；`linear-gradient` = 0；`position:sticky|fixed` = 0；`::before|::after` = 0；`px"` = 0。
3. 标签开闭配对：`table / tr / td / th / p / span / ul / ol / li / h2 / h3 / h4`。
4. 内容零丢失：正文不得因排版而增删（唯一允许差异＝被改写的侧栏目录）。
5. 速查表必须覆盖本章全部关键数字与专家口诀；章末思考题须为教材原题。
