# 中药处方讲解规范

> 供「中药处方讲解」「方剂讲解」功能使用。融合现代方剂学体系与倪海厦经方派讲法。

---

## 一、讲解层次（由浅入深五层）

```
① 方名释义 → ② 出处与经典条文 → ③ 组方结构（君臣佐使）→ ④ 逐味药讲解 → ⑤ 临床运用与加减
```

### 第 1 层：方名释义

- 方名含义拆解（如「白虎」喻西方金神、清阳明大热；「真武」北方水神、温阳利水）
- 类方家族概览（如桂枝汤类、承气汤类、柴胡汤类）

### 第 2 层：出处与经典条文（必出——经方条文卡片）

凡讲经方，条文卡片必出，一卡一方。**卡片规范四要素**：出处 + 原方组成 + 用法 + 倪师临床三行。

```
> **【{方名} · {书名·篇名/第X条}】**
> 「{原文条文}」
> {原方组成逐味+汉代剂量}
> 上{N}味，{煎服法/用法}
> **倪师临床**：{三行——①病机一句话 ②主证眼目一句 ③关键剂量/配伍口述}
```

**完整范例**：

> **【桂枝汤 · 伤寒论第12条】**
> 「太阳中风，阳浮而阴弱，阳浮者，热自发；阴弱者，汗自出。啬啬恶寒，淅淅恶风，翕翕发热，鼻鸣干呕者，桂枝汤主之。」
> 桂枝三两（去皮） 芍药三两 甘草二两（炙） 生姜三两（切） 大枣十二枚（擘）
> 上五味，㕮咀三味，以水七升，微火煮取三升，去滓，适寒温，服一升。
> **倪师临床**：
> ① 病机：太阳中风，营卫不和——阳浮（心阳外张致热自发）阴弱（阴不内守致汗自出）。
> ② 主证眼目：有汗 + 恶风 + 脉浮缓（与麻黄汤证"无汗 + 恶寒 + 脉浮紧"对看）。
> ③ 剂量口述：壮汉桂枝 5 钱、成人 3 钱、瘦子 2 钱、小儿半钱；桂枝白芍等量，阳虚加桂、阴虚加芍；服后喝热稀粥助药力达四末。

**倪师临床三行取材路径**：优先查 `倪海厦体系/references/distilled/05-clinical-dose-quickref.md`（伤寒论 14 方 + 金匮 19 方），未命中再查 `06-clinical-dose-c99.md`（C 类 96 方全量摸查）。无口述剂量时按「一两=一钱」换算兜底并标〔换算〕。

**条文获取方法：**
```bash
python scripts/search_textbooks.py --keyword "{方名}主之" --category 伤寒论,金匮要略
# 或直接搜方名
python scripts/search_textbooks.py --keyword "{方名}" --files "499-金匮要略方论.txt"
```

**倪师药性认识引用（来自 modules/09）**：在逐味药讲解（第 4 层）中，凡涉及单味药，除现代教材基线外，必须并列倪师药性认识。来源：`倪海厦体系/modules/09_zhenjiu_bencao.md`（针灸教程 + 神农本草经 374 种 + 天纪 + 推荐书目 + 汉唐医疗，约 13570 行）。检索方法：

```bash
# 在倪师本草库内 grep 单味药名
# 工具：用 Grep 工具搜 modules/09_zhenjiu_bencao.md，关键词=药名
# 取出倪师对该药的性味/主治/临床配伍口述，与教材对照呈现
```

对照呈现格式：

| 维度 | 现代教材（《中药学》） | 倪师认识（modules/09 + distilled/03） |
|------|---------------------|--------------------------------------|
| 性味归经 | {教材标准} | {倪师口述，如"桂枝壮心阳、加速动脉血流出"} |
| 功效主治 | {教材分条} | {倪师用法，如"白芍活血、加速静脉血回流"} |
| 配伍要点 | {教材对药} | {倪师对药口述，如"桂枝白芍等量调阴阳"} |
| 禁忌 | {教材禁忌} | {倪师禁忌，如"酒客不可用桂枝汤"} |

### 第 3 层：组方结构

| 角色 | 药物 | 职责 | 病机对应 |
|------|------|------|---------|
| **君** | … | 针对主病主证 | … |
| **臣** | … | 辅助君药/针对兼证 | … |
| **佐** | … | 治兼证/制君臣之偏/反佐 | … |
| **使** | … | 引经/调和 | … |

配伍亮点分析：对药（如桂枝-芍药调和营卫）、用量比例（如小承气汤厚朴大黄之比）、特殊煎服法。

### 第 4 层：逐味药讲解

每味药按固定结构：

- **性味归经**：辛甘温·归心肺膀胱经
- **功效**：发汗解肌、温通经脉、助阳化气
- **在本方中的作用**：联系方剂整体病机
- **经典认识补充**：可引《神农本草经》等古籍原文（用检索脚本查本草类目）

```bash
python scripts/search_textbooks.py --keyword "{药名}" --category 本草 --max-hits 5
```

### 第 5 层：临床运用

- **辨证眼目**（用方的关键指征，最简明的抓主证描述）
- **现代应用**：对应现代疾病的参考（注明「仅供参考，须辨证使用」）
- **加减法**：兼证加减逐条列出
- **类方鉴别**：与本方易混的方剂列表对比（表格呈现）
- **禁忌**：禁用、慎用情形 + 毒性药物警示（见 SKILL.md 通用规则）

## 二、剂量换算表（三列对照体系）

经方原方为汉代度量，讲解时必须**同时给出三列剂量**，对照呈现，缺一不可：

| 折算体系 | 汉代一两折算 | 适用场景 | 依据来源 |
|---------|------------|---------|---------|
| **① 原方剂量（柯雪帆考古）** | 一两 ≈ 15.6g | 重症/危症参考；研究仲景原意 | 柯雪帆《伤寒论方剂剂量考》（上海中医药杂志，1983） |
| **② 教材通行量** | 一两 ≈ 3g | 现代中医教育、考试、临床常规 | 现行《方剂学》《伤寒论》教材通行折算 |
| **③ 倪师临床量** | 一两 = 一钱 ≈ 3.75g | 倪海厦经方派临床实战 | 倪师源文件口述+「古方一两→临床一钱」换算（台湾剂量，1 钱≈3.75g） |

**三列剂量输出格式**：

```
| 药物 | 原方剂量 | 教材通行量 | 倪师临床量 |
|------|---------|-----------|-----------|
| 桂枝 | 三两 ≈ 46.8g | 9g | 3 钱 ≈ 11.25g〔口述：壮汉 5 钱/成人 3 钱/瘦子 2 钱/小儿半钱〕 |
| 芍药 | 三两 ≈ 46.8g | 9g | 3 钱〔口述：与桂枝等量，阳虚加桂、阴虚加芍〕 |
| 甘草（炙） | 二两 ≈ 31.2g | 6g | 2 钱〔口述〕 |
| 生姜 | 三两 ≈ 46.8g | 9g | 2-3 片〔口述常例〕 |
| 大枣 | 十二枚 | 12 枚 | 12 枚 |
```

> **取材路径**：原方剂量按柯雪帆折算；教材通行量按现行《方剂学》教材；倪师临床量优先取 `倪海厦体系/references/distilled/05-clinical-dose-quickref.md` 与 `06-clinical-dose-c99.md` 中的〔口述〕行，无口述时按「一两=一钱」换算并标〔换算〕。

**其他汉代单位换算（通用）**：

| 汉代单位 | 折算 | 备注 |
|---------|------|------|
| 一升 | 约 200ml | |
| 一尺 | 约 23cm | |
| 鸡子大 | 约 40-50g | |
| 方寸匕 | 约 5-6g（金石类）/ 2-3g（草木类） | |

**规则：**
1. 默认并列三列剂量，重症用方需重点说明原方剂量与倪师临床量的关系（如"倪师附子平常开 5 钱"vs 原方"附子一枚≈3-4 钱"）。
2. 毒性药（附子、细辛、乌头、半夏、天南星、甘遂、大戟、芫花、巴豆、牵牛子、水蛭、虻虫、斑蝥、蟾酥、马钱子、朱砂、雄黄等）不论剂量大小，必须加 ⚠️ 警示框：剂量上限、炮制要求（生/炮）、煎法要求（附子先煎久煎）、配伍禁忌（十八反十九畏）。
3. 凡倪师口述剂量与教材量差异较大时（如细辛三两→倪师 2 钱 vs 教材 3g vs 原方 46.8g），需说明"倪师量介于教材与原方之间，且按体格分档"。

## 三、经方派（倪师风格）讲解要点（用于口述版/磨耳版）

借鉴 nihaixia skill 的表达规范：

1. **第一人称口语**：「你看这个病人……」「我临床上遇到这种……」
2. **抓主证思维**：先讲「什么情况下想到用这个方」（主证、脉、舌），再讲方义
3. **阴阳为先**：任何方先定位阴阳表里虚实寒热大局
4. **折中格式**：口语正文 + 表格/加粗标注重点（辨证模板：`**辨证：{证型}（{病机}·{方名}证）**`）
5. **剂量务实**：给出倪师常用剂量范围与现代教材剂量并列

## 四、单味中药讲解（非处方场景）

用户问单味药时按此结构：

```
药名 → 性味归经 → 功效主治（分条）→ 经典本草原文（知识库检索）→
配伍应用（对药/经方中的角色）→ 用法用量 → 使用注意与禁忌
```

**检索建议：**
```bash
python scripts/search_textbooks.py --keyword "{药名}" --category 本草 --max-hits 8
python scripts/search_textbooks.py --keyword "{药名}" --files "中药学.txt" --max-hits 5
```

先现代教材定基线，再古籍补充传统认识，两者对照呈现。

## 五、输出质量标准

- 经方必附条文卡片（四要素齐全：出处 + 原方组成 + 用法 + 倪师临床三行），条文需与知识库核对原文（不得凭记忆引错）
- 君臣佐使拆解完整，无「君药不明」情况
- 每味药至少含性味归经 + 本方作用两项；凡倪师体系内单味药，必须并列倪师药性认识（来自 modules/09）
- 剂量采用**三列对照**：原方剂量（一两≈15.6g）+ 教材通行量（一两≈3g）+ 倪师临床量（一两=一钱≈3.75g，含体格档位口述）
- 毒性药物（附子、细辛、乌头、半夏、天南星、甘遂、大戟、芫花、巴豆、牵牛子、水蛭、虻虫、斑蝥、蟾酥、马钱子、朱砂、雄黄等）必须加 ⚠️ 警示框：剂量上限、炮制要求（生/炮）、煎法要求（如附子先煎久煎）、配伍禁忌（十八反十九畏）
