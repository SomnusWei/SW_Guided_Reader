# 中药学讲义体例规范（默认输出格式）

> 适用范围：主题为**中药学**的讲义制作——**单味中药专论**（如麻黄、桂枝、石膏），或按药材类别成章（如解表药、清热药、补虚药）。
> 命中文档的判据见 SKILL.md「功能二 · 讲义体例路由」。
> **本规范为中药学讲义的默认输出格式，无需用户指定。**

---

## 一、体例蓝本（动手前必读）

**蓝本文件**：`references/examples/中药学-麻黄讲义_OneNote版样板.html`

该文件是一份**完整成品**（《中药学》各论 · 第八章 解表药 · 第一节 发散风寒药 · **麻黄单味药专论**，共十节）。
本规范的全部约定都以它为准。**动手写之前先通读蓝本**，逐段对照，确保骨架、栏目、字号一致；
遇到本规范未覆盖的细节，一律以蓝本的实际写法为准。

> 🎨 **配色随药性变**：蓝本麻黄为**温性**药，其棕橙色族（`#ab5f13`）即第五节配色表中「温」档。
> 其他药性档的取值见 **5.1 药性配色**，骨架与栏目照蓝本、**色值照 5.1 对应档**。

> ⚠️ **本类体例与方剂学／生理学体例的最大差别**：章标题**不带 ［…］ 彩色标签**。
> 方剂学用 `［目标］`、生理学用 `［第一节］`；**中药学体例明确不用**，标题直接是「一、药材与来源」这样的正文序号。
> 详见第三节与第七节第 1 条（质检逐条查）。

## 二、交付形态

| 项 | 规定 |
|---|---|
| 交付格式 | **OneNote 原生 HTML**（已是导入优化形态，无需再转换） |
| 文件命名 | `<药名>_中药学讲义_OneNote版.html`（如 `麻黄_中药学讲义_OneNote版.html`） |
| 导入方式 | OneNote 中「插入 → 文件 → 作为打印输出插入」，或粘贴时选「保留源格式」 |
| 为什么 | 全部内容以表格承载，OneNote 粘贴网页时丢失的浮动/粘性/伪元素/外部样式表在此形态下均不存在，表格结构、底纹与分色标注可完整保留 |

**放弃的写法**：不使用 `div` 布局、不使用 `class` 属性、不使用 CSS 变量、不使用渐变与圆角、
不使用 `position:sticky/fixed`、不使用 `::before/::after`、字号一律 `pt`（不得出现 `px`）。

**底稿策略**：网页版底稿（class 驱动）同时保留，用 `scripts/to_onenote.py`
转换生成交付物（**禁止手写 OneNote 版**）：

```bash
python scripts/to_onenote.py --src "<药名>_中药学讲义.html" \
    --out "<药名>_中药学讲义_OneNote版.html" \
    --primary "<5.1 表中该药药性的主题色>" --check
```

> 本类体例**以原生形态直接编写**（照蓝本写，不经 `to_onenote.py` 转换；转换会丢底纹、叠加 `▍`）。
> 上面的命令仅在确需从网页版底稿转换时使用，此时 `--primary` 必须传 5.1 表中该药药性档的主题色。

## 三、整体骨架（十节固定）

```
① 封面表            单格 bgcolor 主题深色（该档，见 5.1）
② 目录表            目 录 + 说明（教材基线／专家体系／体例）+ 三级条目
③ 一、药材与来源      （含饮片图位）
④ 二、药性（性味归经）
⑤ 三、功效
⑥ 四、应用
⑦ 五、用法用量与炮制
⑧ 六、使用注意
⑨ 七、现代研究
⑩ 八、专家视角
⑪ 九、类药鉴别
⑫ 十、速查表与小结
```

**章标题格式（硬性）**：

```
<h2 class="sec" id="sN">一、药材与来源</h2>        ✅ 正确
<h2 class="sec" id="sN"><span class="num">概览</span>一、药材与来源</h2>   ❌ 禁止
```

- 标题内容一律为「**<中文序号>、<标题>**」，**不得带 ［…］ 彩色标签**。
- 转换器会为 `.sec` 标题自动追加一条 **3px 主题色分隔条**，此条保留。
- 一级层次用 `h2`（十节），节内用 `h3`（如「（一）风寒感冒」），再下用 `h4`（如「此外」）。
- `h3/h4` 转换后自带 `▍` 前缀（本类体例保留）。

**一节一页**：单味药专论通常一页（约 1～1.5 万字）；若做**整章多味药**讲义，按药拆成多个
`<药名>_中药学讲义_OneNote版.html`。

| 行 | 内容 | 样式 |

| 2 | 药名；其后 `<small>` 附 `拼音 · 出处（《神农本草经》等）· 一句话定调` | 23pt 白色加粗 ＋ 12.5pt |
| 3 | 来源行：`教材基线：`／`专家体系：`／（必要时）`倪海厦经方体系：` | 9.5pt，标签用 `strong`（深底自动反白） |
| 4 | 标签行：3 枚 `<span>`，如 `单味药专论`／`共10节`／`含饮片形态要点` | 9pt |

### 4.2 目录表

→ 一级条目（十节）→ `li.l2` 二级条目（第四节下的三个主治）。

### 4.3 十节内容规范

| 节 | 必含栏目 | 形态 |
|---|---|---|
| **一、药材与来源** | ① 教材基线卡：来源（含拉丁学名/药用部位）· 主产 · 采收加工 · 性状 · 炮制；② **饮片图位**（见 4.4）；③ 提示卡（易忽略的细节） | 卡片 ＋ 图位 |

| **三、功效** | ① 教材基线卡：【功效】原文；② **专家卡**：表述之辨（共性表述 vs 个性表述、该不该改字）；③ **考点边界卡**：教材口径 vs 专家口径，注明"考试以教科书为准" | 卡片 |
| **四、应用** | 每个主治一个 `h3`（如「（一）风寒感冒」），各含：教材基线卡（主治+配伍+代表方表）＋ 专家卡（个性特征/最佳主治/配伍机宜）；末设 `h4 此外` | 卡片 ＋ 表 |
| **五、用法用量与炮制** | ① 教材基线卡：【用法用量】；② **炮制表**：`炮制品 ｜ 饮片形态（认药要点） ｜ 处理 ｜ 成分变化 ｜ 作用变化`（**"饮片形态"列必含**）；③ 专家卡：炮制机制与存疑 | 卡片 ＋ 表 |
| **六、使用注意** | ① **警示卡**（`card-boundary`）：教材【使用注意】原文，毒性药必附剂量上限/煎法/禁忌；② 专家卡：只记"特殊"的 | 卡片 |
| **七、现代研究** | ① 教材基线卡：化学成分（含药典含量指标）· 药理作用；② 专家卡：若专家有"五步取证"式论证，做成 `取证步骤 ｜ 证据` 表，并附其对证据的附加要求 | 卡片 ＋ 表 |
| **八、专家视角** | 每位专家一张独立卡（**一句定调 → 取舍法/方法论 → 原话引文块**） | 卡片 ＋ 引文块 |
| **九、类药鉴别** | ① 鉴别表：`鉴别要点 ｜ 本药 ｜ 同类4味 ｜ 易混药`（行含大类/教材功效/个性/兼长/同出一物）；② **易错点卡**（2～3 条必须分清之处） | 表 ＋ 卡片 |
| **十、速查表与小结** | ① **一览速查表**：`项目 ｜ 内容`（来源/药性/功效/主治/此外/用法/注意/关键成分/个性特征）；② **要点提炼**大字块（`div.big`，`<br>` 分行）；③ **小结框**（`summary-box`） | 表 ＋ 大字 ＋ 小结框 |

### 4.4 饮片图位（本类体例特色）

单味药讲义**宜配 1 处饮片图位**（认药需要），置于第一节「一、药材与来源」。

| 项 | 规定 |
|---|---|
| 写法 | `<div><img src="…" alt="…" width="640" data-caption="…"></div>` |
| 转换后 | 自动成为白底框表格 ＋ 图注（`data-caption` 生成图注行） |
| 图注固定句式 | `图　<饮片名>（示意图，非实拍）——<形态要点>。若要用于认药，建议替换为实拍饮片照片` |
| 换图 | `src` 换成本地 **base64 data URI**（离线可用、导入 OneNote 不依赖联网）或图片 URL |
| 加图位 | 整块复制该 `<div>`，改 `alt` 与 `data-caption` |

**硬性约束**：
1. `data-caption` 内**不得出现英文双引号**（会截断属性）——用中文引号 `“ ”` 或 `「 」`。
2. **不得拿"生成兜底图／占位图"冒充实拍**——凡非实拍图，图注必须如实标注"示意图，非实拍"。
3. 若图像接口对药材/饮片类提示词返回同一张兜底图（实测会出现），**宁可只留 1 个图位**，
   也不要把同一张图重复标成"图1生麻黄／图2蜜炙／图3麻黄绒"——那是失实标注。
4. 饮片形态的教学信息**同时以文字保留**在第五节炮制表的「饮片形态」列，做到"图可换、信息不丢"。

## 五、样式约定

### 5.1 药性配色（先定色调，再动手）★

**本类讲义的色调由该药药性的「四气」决定**：寒凉药走冷色（靛蓝／青碧），温热药走暖色（琥珀／朱），平性药走中性的棕金。
除此之外骨架、栏目、字号一律照蓝本——**只换色，不换结构**。

**定档规则**

| 情形 | 取档 |
|---|---|
| 单味药专论 | 按教材【药性】的四气定档；程度词归并：大寒／寒 → **寒**；微寒／寒凉／凉 → **凉**；微温／温 → **温**；大热／热 → **热**；标「平」或不标四气者 → **平** |
| 整章／多味药讲义 | 取该**节**主导药性（如「发散风寒药」→ 温）；章节内寒热并列无法归一（如清热药下分清热泻火／清热燥湿／清热解毒）时，按**节**分别定档 |
| 节内仍寒热混杂 | 退化为**平**档 |
| 一档到底 | 全篇只用该档一组色，**不得中途换档、不得混用两档的色值** |

## 六、专家内容标注与边界（必须遵守）

- 本类讲义的专家体系：**仓颉蒸馏专家**「张廷模·中药学」（调用规则见 `references/zhangtingmo-integration.md`）
  ＋ 固定专家库中的**倪海厦经方体系**（中药/本草部分，见 `references/nihaixia-integration.md`）。
- 一切专家观点以**独立卡片**与教材并列，标注来源，**不替代教材结论**。
- **教材／药典口径与专家口径不一致者必须并列呈现**，并注明"考试以教科书为准"。
  例：麻黄功效教材作「宣肺平喘」、张廷模主张「平喘止咳」；桂枝教材作「发汗解肌」、张廷模主张「发汗解表」。
- 蒸馏专家的**课堂层与专著层口径若不一致**（如葛根"解肌"：讲稿回避、专著保留），
  须**分别标注层次**，不得择一冒充唯一立场。
- 涉及具体治疗与剂量时，附"仅供参考，临床应用请在执业医师指导下进行"。
- **不设「使用说明卡」**（全库统一规定）：取材与标注规则、边界声明改由**每张专家卡自身**承担；
  免责句内联到涉治疗与剂量的卡片（含运动员禁用、高血压/失眠慎用等安全项直接写在第六节警示卡内）。

## 七、硬性格式规则（质检会逐条查）

1. **章标题不得带 ［…］ 标签**：全文 `［`、`］` 计数应为 **0**；`class="num"` 计数应为 **0**。
   （若沿用方剂学/生理学模板，务必删除 `<span class="num">…</span>`。）
2. `class="` 出现次数 = 0；`var(--` = 0；`linear-gradient` = 0；`position:sticky|fixed` = 0；`::before|::after` = 0；`px"` = 0。
3. 标签开闭配对：`table / tr / td / th / p / span / ul / ol / li / h2 / h3 / h4`。
4. 内容零丢失：正文内容不得因排版而增删（唯一允许差异＝被改写的侧栏目录）。
5. **速查表必须覆盖**该药全部关键项（来源/药性/功效/主治/此外/用法/注意/关键成分/个性特征）。
6. **图注须如实**：非实拍图必须标注"示意图，非实拍"；不得重复标注同一张图。
7. **毒性／特殊药物**（附子、川乌、细辛、麻黄、朱砂、雄黄、马钱子等）必附
   ⚠️ 使用注意与禁忌（剂量上限、煎法、慎用/禁用人群）。
8. 正文引号统一用中文全角 `“ ”`（配对），属性值内不得用英文双引号。
9. **不得出现「使用说明卡／专家内容使用说明与边界声明」**（全文该标题计数应为 0）；
   免责与安全内容改由正文承担：涉治疗与剂量的卡片内联免责句，安全项写在第六节警示卡内。
10. **配色与药性一致**：主题色／主题深色／教材基线卡三色／小结框两色／隔行底纹／专家卡四色／引文块字色，
    必须全部取自 **5.1 表中同一档**（寒 `#23557d`／凉 `#1a6f69`／平 `#8a5b00`／温 `#ab5f13`／热 `#b03a26`），
    不得混档、不得留用他档残留值；语义卡色保持固定。
