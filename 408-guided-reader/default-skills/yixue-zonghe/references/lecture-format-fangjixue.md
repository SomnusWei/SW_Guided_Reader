# 方剂学讲义体例规范（默认输出格式）

> 适用范围：主题为**方剂学**的讲义制作（按「剂」成章，如泻下剂、解表剂、和解剂、清热剂、补益剂……）。
> 命中文档的判据见 SKILL.md「功能二 · 讲义体例路由」。
> **本规范为方剂学讲义的默认输出格式，无需用户指定。**

---

## 一、体例蓝本（动手前必读）

**蓝本文件**：`references/examples/方剂学-泻下剂讲义_OneNote版样板.html`

该文件是一份**完整成品**（《方剂学》泻下剂：寒下·温下·润下·逐水·攻补兼施五节合一），
本规范的全部约定都以它为准。**动手写之前先通读蓝本**，逐段对照，确保骨架、栏目、配色、字号一致；
遇到本规范未覆盖的细节，一律以蓝本的实际写法为准。

---

## 二、交付形态

| 项 | 规定 |
|---|---|
| 交付格式 | **OneNote 原生 HTML**（已是导入优化形态，无需再转换） |
| 文件命名 | `<主题>方剂学讲义_OneNote版.html` |
| 导入方式 | OneNote 中「插入 → 文件 → 作为打印输出插入」，或粘贴时选「保留源格式」 |
| 为什么 | 全部内容以表格承载，OneNote 粘贴网页时丢失的浮动/粘性/伪元素/外部样式表在此形态下均不存在，表格结构、底纹与分色标注可完整保留 |

**放弃的写法**：不使用 `div` 布局、不使用 `class` 属性、不使用 CSS 变量、不使用渐变与圆角、
不使用 `position:sticky/fixed`、不使用 `::before/::after`、字号一律 `pt`（不得出现 `px`）。
这些正是 OneNote 会丢弃或导致错位的特性。

## 三、整体骨架（上篇／中篇／下篇）

```
① 封面表           单格 bgcolor 主色 #4a1a10
② 说明行           8.5pt 灰字，一句话说明转换形态
③ 目录表           目 录 + 体例说明 + 三级条目
④ 上篇 · 总论       四节（见 4.1）
⑤ 中篇 · 各论       章分隔表 → 章引言 + 专家卡 → 每方七层（见 4.2）
⑥ 下篇 · 附录       四个附录（见 4.3）
```

**篇分隔**用单格表格实现，文字加字距，如：

```
内 容：中 篇 · 第 一 章 寒下剂        （中/下篇）
内 容：下 篇 附 录
```

## 四、各层栏目与表格 schema

### 4.1 上篇 · 总论（固定四节）

| 章节标题 | 内容与表格 schema |
|---|---|
| `▍一、立法依据与适应范围` | 双格卡：引经典原文（《素问》等）说明立法依据；说明何谓本类方剂、适用何证 |
| `▍二、分类与代表方` | 表：`分类 ｜ 适用证候 ｜ 主要病机 ｜ 代表方（本讲义收录）`；表后接一句「一法多类」的主线总结 |
| `▍三、使用注意（下法通则）` | 双格卡逐条列出使用注意；另设 ⚠️ 红色警示卡（**禁忌速记**）与浅色「读法提示」卡 |
| `▍四、专家总论` | 每位专家一张独立卡片（卡头为嵌套小表：标题 ｜ 来源徽标），随后一张「两专家分工」说明卡 |

### 4.2 中篇 · 各论

**每章**（一章 = 一「剂」，如寒下剂）按：

1. 篇分隔表 → 章名
2. 章引言卡（本章适用证候 + 代表方 + 与其他章的分界）
3. 专家观点卡（每位专家一张，标注来源）
4. 逐方展开 —— **每首方剂按七层**（原文照录，不得增删层次）：

> 每一首方剂按以下七层展开：
> ① 组成用法 ② 功用主治 ③ 证治机理 ④ 配伍结构（君臣佐使）
> ⑤ 剂量使用讲解（原方—教材—倪师临床三列） ⑥ 附方 ⑦ 运用与鉴别。
> 每方之后附**倪海厦方义解析**与**邓中甲方义解析**两张专家卡片；篇末附中药小讲义与速查表。

| 层 | 栏目 | 形态 |
|---|---|---|
| ① | 组成用法 | 卡片：`【组成】` 逐味列明（含炮制与用量）、`【用法】` |
| ② | 功用主治 | 卡片：`【功用】`／`【主治】`（含主要症状群） |
| ③ | 证治机理 | 卡片：病机推演，症状 → 病机的对应 |
| ④ | 配伍结构（君臣佐使） | 卡头 `▍` 三级标题；表：`角色 ｜ 药物 ｜ 职责 ｜ 病机对应` + 配伍亮点分析 |
| ⑤ | 剂量使用讲解 | 表：`药物 ｜ 原方剂量 ｜ 教材通行量 ｜ 倪师临床量 ｜ 本章用量要点`（三列对照，读法见 `references/prescription-guide.md`） |
| ⑥ | 附方 | 附方逐首给出 `方名（出处）｜组成｜功用｜主治`，并说明与本方的源流关系 |
| ⑦ | 运用与鉴别 | ⚠️ 使用注意卡 + 鉴别要点表：`鉴别要点 ｜ 本方 ｜ 类方A ｜ 类方B …` |

### 4.3 下篇 · 附录（四个，固定）

| 附录 | 标题 | 表格 schema |
|---|---|---|
| 附录一 | 中药小讲义——本剂主药（N 味） | 逐味一段双格卡，内容同「单味中药讲解」（见 `references/prescription-guide.md` 第四节） |
| 附录二 | 中药小讲义——本剂常用配伍药（N 味） | 同上 |
| 附录三 | 方剂速查表 | 表：`分类 ｜ 方名（出处） ｜ 组成 ｜ 功用 ｜ 主治要点`——覆盖正文全部方剂（正方 + 附方） |
| 附录四 | 剂量对照速查表（原方—教材—倪师临床） | 表：`药物 ｜ 原方剂量 ｜ 教材通行量 ｜ 倪师临床量 ｜ 本章用量要点`；表前加「三列剂量体系的读法」说明卡 |

> ⚠️ 本类体例**不设**「专家内容使用说明与边界声明」附录（全库统一规定）。
> 取材与标注规则、边界声明改由**每张专家卡自身**承担（见第六节），免责句内联到涉治疗与剂量的卡片。

## 六、专家内容标注与边界（原文规定，必须遵守）

- 标注「**倪海厦观点**」者为倪海厦体系专论。
- 标注「**邓中甲**」者出自《邓中甲方剂学讲稿》**授课实录**——该讲义为讲稿整理本，**非仓颉蒸馏产出，故不标「蒸馏Skill」**。
- 凡两位专家库中确无专论之方，仅按其在本章其他方剂中反复申明的**通用原则**作推演，并在卡片标题标注「**推演**」，**不作臆造、不假托原话**。
- 凡字句差异出现于讲稿转写本者，**以教材《方剂学》为准**。
- 专家观点一律以**独立卡片**与教材并列，**每张卡自身**写明取材与边界（不设专门的说明附录）。

## 七、硬性格式规则（质检会逐条查）

1. **不得出现时间戳**：全文不得有 `P## [hh:mm:ss]`、其区间形式（如 `P09 [00:12:28–00:12:45]`）、
   **以及无讲次前缀的续段**——这类最易漏删：
   `刘忠保·第 9 讲 / [00:39:38–00:42:15]` 中的 `[00:39:38–00:42:15]` 同样必须清除。
   专家出处一律用可读形式（如「邓中甲·泻下剂讲」「倪海厦·阳明篇」）。
   `P## [hh:mm:ss]` 这类**记法示例**（写在使用说明里解释引用格式的）也在禁止之列。
   **清洗工具**（底稿或既有讲义含时间戳时，先清洗后交付）：

   ```
   python scripts/strip_timestamps.py --in <讲义>.html --dry-run --check   # 先预演看命中数
   python scripts/strip_timestamps.py --in <讲义>.html --inplace --check   # 确认后原地清洗
   ```

   该脚本兼容三种形态（网页版 `span.ts`、OneNote 版内联样式 span、裸文本），同时清掉删除后
   遗留的多余空白，并会改写「所有引用均带 … 出处」这类随之变成残句的说明文字。**清洗后须复跑一次
   `--check`，残留应为 0**（幂等：已清洁的文件再跑不产生任何改动）。
2. `class="` 出现次数 = 0；`var(--` = 0；`linear-gradient` = 0；`position:sticky|fixed` = 0；`::before|::after` = 0；`px"` = 0。
3. 标签开闭配对：`table / tr / td / th / p / span / ul / ol / li / h2 / h3 / h4`。
4. 内容零丢失：正文内容不得因排版而增删（唯一允许差异＝被改写的侧栏目录）。
5. 附录三速查表必须覆盖正文**全部**方剂（正方与附方），附录一、二必须覆盖正文出现的全部中药。
