# 中医内科学讲义体例规范（默认输出格式）

> 适用范围：主题为**中医内科学**的讲义制作——按**教材章**成篇（如肺系病证、心系病证、脾胃病证），
> 章内按**病证**分节，每节统按六层推进。
> 命中文档的判据见 SKILL.md「功能二 · 讲义体例路由」。
> **本规范为中医内科学讲义的默认输出格式，无需用户指定。**

---

## 一、体例蓝本（动手前必读）

**蓝本文件**：`references/examples/中医内科学-心系病证讲义_OneNote版样板.html`

该文件是一份**完整成品**（《中医内科学》新世纪第五版 **第六章 心系病证·五节全**：心悸、胸痹、不寐、多寐、心衰，
含章首「心系病证概要」与三个附录），约 31 万字符。
本规范的全部约定都以它为准。**动手写之前先通读蓝本**，逐段对照，确保骨架、栏目、字号、色值一致；
遇到本规范未覆盖的细节，**一律以蓝本的实际写法为准**。

> ✅ **本蓝本天然对齐规范**：证治分类表已含「主症（含舌脉）」列（5 张表）、附录三即「经方专家库速查表」
> （**不设**「专家视角使用说明与边界声明」附录）、目录只到章节两级（无 `padding-left:14px` 子项）、
> 全文无 `class`/CSS 变量/linear-gradient/青色主题色残留。生成新讲义时**直接照此骨架写**。

> ⚠️ **本类体例以原生形态直接编写**（照蓝本写，**不经 `to_onenote.py` 转换**——
> 实测再转一次会丢约 45% 底纹、`▍` 前缀重复叠加、并插入一张空目录表）。

## 二、交付形态

| 项 | 规定 |
|---|---|
| 交付格式 | **OneNote 原生 HTML**（已是导入优化形态，无需再转换） |
| 文件命名 | `中医内科学-<章名>病证讲义_OneNote版.html`（如 `中医内科学-肺系病证讲义_OneNote版.html`） |
| 导入方式 | OneNote 中「插入 → 文件 → 作为打印输出插入」，或粘贴时选「保留源格式」 |
| 为什么 | 全部内容以表格承载，OneNote 粘贴网页时丢失的浮动/粘性/伪元素/外部样式表在此形态下均不存在 |

**放弃的写法**：不使用 `div` 布局、不使用 `class` 属性、不使用 CSS 变量、不使用渐变与圆角、
不使用 `position:sticky/fixed`、不使用 `::before/::after`、字号一律 `pt`（不得出现 `px`）。

**每章一份**：一章一页（肺系八节约 44 万字符）。章数多时按章拆成多个文件，**不合并成一本**。

## 三、整体骨架

```
① 封面表            单格 bgcolor 主题深色 #012d6a
② 目录表            目 录 ＋ 说明四行（教材基线／辅助教材／古籍参照／专家体系）＋ 两级条目
③ 章标题（h2）        ［第N章］　<章名>        ← 带 ［…］ 彩色标签
④ 章首概要（h3）     ▍<章名>概要
                     h4：（一）辨病范围：本章讲什么 ／（二）辨证治疗总纲 ／（三）专家视角
⑤ 各节（h3）         ▍第一节　<病名>（病名二字之间加全角空格做对齐，如「感　　冒」）
                     h4：（一）辨病 →（二）病因 →（三）病机分析 →（四）辨证论治
                        →（五）临证备要与预防调护 →（六）专家视角
                     节内固定栏目（按蓝本位置摆放）：教材基线卡 8～9 张（随六层分布）／
                     临床联系卡 2 张／古籍摘要卡 1 张／记忆框架卡 1 张／
                     高频考点·低频易混双栏 1 处／三张专家卡（各 1 张）；考点边界卡按需 0～2 张
⑥ 附录（h2）         ［附录一］<章名>方剂速查表（h4：甲、核心方剂详解表／乙、方名索引）
                     ［附录二］<章名>药物速查表
                     ［附录三］经方专家库速查表（四张表，见 4.6）
```

> ⚠️ 本类体例**不设**「专家视角使用说明与边界声明」附录（全库统一规定，见第七节规则 11）。
> 取材／标注规则／边界声明改由**每张专家卡自身**承担（见第六节），不再单列附录。

**层级与标签（硬性）**：

| 层级 | 标签 | 前缀 | 示例 |
|---|---|---|---|
| 章／附录 | `h2` | **带 ［…］ 彩色标签**（`<strong style="color:#b8860b;font-size:11.5pt;">［第四章］</strong>`） | `［第四章］　肺系病证` |
| 节 | `h3` | `▍` | `▍第一节　感　　冒` |
| 层 | `h4` | `▍` | `▍（四）辨证论治` |

> 与方剂学／生理学／中药学体例的差别：**中医内科学体例的章标题带 ［第N章］／［附录N］ 标签**（不删），
> 节与层用 `▍`。转换器不再介入，标签与 `▍` 均照蓝本原样。

每个 `h2` 之下紧跟一条 **3px 主题色分隔条**：

<tr><td bgcolor="#014198" style="background-color:#014198;height:3px;line-height:3px;font-size:1pt;">&nbsp;</td></tr></table>

## 四、各层栏目与表格 schema

### 4.1 封面表

| 行 | 内容 | 样式 |
|---|---|---|
| 1 | kicker：`中医内科学 · 第N章 <章名>` | 10pt，`letter-spacing:2pt`，浅色字 `#e8eefb` |
| 2 | 讲义名（23pt 白色加粗）＋ 副题（12.5pt，`#e4eaf6`，如「辨病　辨证　病因　病机　理法方药一线贯通」） | — |
| 3 | 四行元信息：`教材基线`（书名·版次·主编·章）／`辅助教材`／`古籍参照`／`专家体系`（**三位：倪海厦 · 娄绍昆 · 经方专家库**） | 9.5pt，行高 1.7，标签用 `strong` |
| 4 | 标签行：`倪海厦 · 经方六经　｜　娄绍昆 · 方证腹诊　｜　经方专家库 · 多源合成　｜　OneNote 适配版` | 9pt |

封面表整体为**单格表**，`bgcolor="#012d6a"`（同时写 `background-color`），内边距 `22px 24px`。

### 4.2 目录表

表头「目 录」，其下含：

- **说明四行**：`教材基线：…` / `辅助教材：…` / `古籍参照：…` / `专家体系：倪海厦（经方六经）· 娄绍昆（方证辨证）· 经方专家库（多源合成）`。
- **两级条目**：分组标题 `第四章 · <章名>`（主题色 9.5pt 加粗）＋ 附录分组 `附录`；
  其下**只列到「章」与「节」两级**——`· <章名>概要`、`· 第一节　感冒` …… 与 `· 附录一 …`～`· 附录四 …`。

> ⚠️ **不列节下子项**（硬性）：目录中**不得出现** `· 辨病 · 病因 · 病机分析 · 辨证论治 · 临证备要 · 专家视角`
> 这类 `padding-left:14px` 的子条目行。每节的层次已在正文 `h4` 中呈现，目录保持两级。

### 4.3 章首概要（h3「▍<章名>概要」）

| 层 | 必含栏目 |
|---|---|
| （一）辨病范围：本章讲什么 | 本病的范围界定、收哪些病、与相邻章的分工；一张「收病范围」表 |
| （二）辨证治疗总纲 | 本章各病共用的辨证思路与治则；**教材口径为主**，附一张总纲表 |
| （三）专家视角 | **三张专家卡**（倪海厦／娄绍昆／经方专家库） |

### 4.4 各节六层（h4 顺序固定）

| 层 | 必含栏目 | 形态 |
|---|---|---|
| **（一）辨病** | 概念与范围 · 病名沿革 · 诊断要点 · 鉴别诊断 | 教材基线卡 ＋ 表 |
| **（二）病因** | 外感／内伤分类 · 各家病因观 | 教材基线卡 ＋ 表 |
| **（三）病机分析** | 基本病机 · 病位 · 病理性质 · 病理因素 · 演变转归 | 教材基线卡 ＋ 表 |
| **（四）辨证论治** | 辨证要点 · 治则治法 · **证治分类**（每证型：主症 · 治法 · 代表方 · 常用药 · 随证加减） | 教材基线卡 ＋ 每证型一表 |
| **★证治分类表列结构（硬性）** | 表头六列：`证型` → `主症（含舌脉）` → `证机概要` → `治法` → `代表方` → `常用药（要点）`；`随证加减` 列于表后独立卡片。**主症列不得缺**——须逐证型列出该型的核心症状＋舌象＋脉象（如"心悸善惊，烦躁不安，失眠多梦；舌淡苔薄，脉细或细数"），仅写"证机概要"不算主症。<br><br>**四列须取教材原文**：`主症`／`证机概要`／`治法`／`代表方` 四列内容**必须逐字取自《中医内科学》教材对应证型原文**，不得改写、不得概括、不得用自己的话重述。`常用药` 可据教材整理但须列出原方组成；`随证加减` 须标注"教材原文"或"编者整理"。 |

## 六、专家内容标注与边界（必须遵守）

- **默认专家体系（三位，缺一不可）**：
  ① **倪海厦经方体系**——见 `references/nihaixia-integration.md`；
  ② **娄绍昆·方证辨证**——见 `references/laoshaokun-integration.md`；
  ③ **经方专家库（多源合成）**——见 `references/jingfang-integration.md`。
- 一切专家观点以**独立卡片**与教材并列，**不替代教材结论**；每张卡必须写明取材与边界。
- **经方专家库必须点名到人**：谦斋（秦伯未）／姚荷生／印会河／赵绍琴／教材口径／《名老中医之路》某篇作者；
  **禁止**写成"经方派认为""中医认为"这类抹平归属的表述；各家不一致处**如实并列，不调和**。
- **三级来源须分清**（调用经方专家库时最易出错的三处）：
  ① 《谦斋中医处方学》《谦斋四大经典简释》中的「编按」是**编者孙其新转述**，不是秦伯未原文；
  ② 《赵绍琴内科学》上篇各节【治验】按语多为**师门弟子手笔**（文中称「赵师」）；
  ③ 《名老中医之路》是**多作者合集**，须署篇名与作者，其编者/出版社/版本**未能从文本确认**。
- **引文铁律**：卡片中的每一句原话必须**逐字**取自素材，**不得改写、不得把不相邻的句子合并成一句引文**；
  原文有插叙或跨页隔断时，用「……」标明省略并在出处行加注（例：「原句跨页，第51页页脚与下页页眉隔断，以省略号标示」）。
- **证据强度照录不升级**：素材写「有一部分病人收效甚好。亦有无效的，其原因有待解决」者，
  调用时不得简化为"有效"；各家明说「不敢肯定／尚待过关／个人不敢开／仍需进一步研究」者，照录为边界。
- 涉具体治疗与剂量时，附"仅供参考，临床应用请在执业医师指导下进行"。
- **病种特殊提示必写**（写在**该节（五）临证备要与预防调护**的警示卡内，不单列附录）：肺痨以**西医规范抗结核治疗为主**、须完成全部疗程；肺胀神昏、喘脱、大咯血等急危重证**须及时急诊处理**。

## 七、硬性格式规则（质检会逐条查）

1. **目录只到两级**：不得出现 `padding-left:14px` 的节下子项行（如 `· 辨病 · 病因 · 病机分析 · 辨证论治 · 临证备要 · 专家视角`），计数应为 **0**。
2. **三位专家卡齐全**：每节（六）专家视角内**三张卡**（徽标 `倪海厦`／`娄绍昆`／`经方专家库`）各一，章首概要节同样三张；
   全文徽标计数：`倪海厦` = 节数＋1、`娄绍昆` = 节数＋1、`经方专家库` = 节数＋1＋4（附录四四张卡）。
3. **主题色一致**：全文主题色族只允许 5.1 表中取值；**不得残留其他主题色**（如青 `#0f6b6b`、深青 `#0a4b4b`）。
4. `class="` 出现次数 = 0；`var(--` = 0；`linear-gradient` = 0；`position:sticky|fixed` = 0；`::before|::after` = 0；`px"` = 0。
5. 标签开闭配对：`table / tr / td / th / p / span / strong / br / h2 / h3 / h4`。
6. 每个 `h2` 下必须有 3px 主题色分隔条；每个 `h3`（节）必须有 `▍` 前缀。
7. **六层不缺项**：每节 `h4` 依次为 （一）辨病 →（二）病因 →（三）病机分析 →（四）辨证论治 →（五）临证备要与预防调护 →（六）专家视角。
8. **节内固定栏目齐全**（按 4.4 数量表）：古籍摘要卡 1 ／ 记忆框架卡 1 ／ 高频考点·低频易混双栏 1 ／ 临床联系卡 2 ／ 三张专家卡各 1 ／ 教材基线卡 8～9。
9. **附录三不缺**：经方专家库速查表四张卡（七模型／病证矩阵／原话精选／使用纪律与边界）。
10. **引文逐字**：新增/引用的每一句原话都能在对应素材中逐字检出（可按 5.1 的归属核对方法回搜）。
11. **不得出现「专家视角使用说明与边界声明」附录**（全文该标题计数应为 0）。
    免责与安全内容改由正文承担：① 涉具体治疗与剂量的卡片内联"仅供参考，临床应用请在执业医师指导下进行"；
    ② 病种特殊提示写在该节**（五）临证备要与预防调护**的警示卡内（见第六节末条）。
12. 内容零丢失：正文不得因排版而增删（唯一允许差异 = 被改写的目录与色值）。
13. **证治分类表须含主症列**：每张证治分类表头必须为六列——`证型` → `主症（含舌脉）` → `证机概要` → `治法` → `代表方` → `常用药（要点）`。
    **主症列不得缺**，且每证型必须列出核心症状＋舌象＋脉象（"气血亏损，心虚胆怯"这类属证机概要，不算主症）。
14. **证治分类四列须取教材原文**：`主症`／`证机概要`／`治法`／`代表方` 四列必须**逐字**取自《中医内科学》教材对应证型原文，不得改写、概括或自撰。
    质检时抽查每表至少 1 个证型，用检索脚本在教材原文中逐字定位（须命中）；命中失败即视为违规。
15. **OCR 错字必查**：教材为 OCR 文本，提取前必须做 OCR 错字核验，重点检查：
    - **形近字**：如「㿠」误为「恍」「光」、「脘」误为「皖」「腕」、「溲」误为「搜」「叟」、「颧」误为「颧」、「咯」误为「咯」、「悸」误为「季」、「窒」误为「室」；
    - **音近字**：如「痰」误为「谈」、「湿」误为「温」、「瘀」误为「淤」、「濡」误为「儒」、「弦」误为「玄」；
    - **中医术语**：方名（如「参附汤」误为「参付汤」、「苓桂术甘汤」误为「苓桂术甘汤」）、药名（如「薤白」误为「薤百」、「瓜蒌」误为「瓜娄」）、脉象名（如「结代」误为「结伐」）、舌象名（如「紫暗」误为「紫暗」）；
    - **漏字/多字**：OCR 常见漏行、串行，须核对上下文逻辑。
    核验方法：① 用 `scripts/ocr_check.py` 对提取的证型文本做形近/音近词典扫描；② 回搜教材原文核对方名、药名、脉象名；③ 不确定处标注「[OCR 存疑]」并保留原字，不得擅改。

## 八、质检

```bash
# 1. 内容准确性：证治分类四列教材原文 + OCR 错字核验
python scripts/ocr_check.py <教材提取的证型文本.txt>   # OCR 错字扫描（形近字/方名/药名/脉象/舌象）

# 2. HTML 形态
python scripts/validate_html.py <讲义_OneNote版.html>              # 通用项（内容准确性 P0/P1/P2）
python scripts/to_onenote.py --check-only <讲义_OneNote版.html>     # OneNote 形态 6 项残留 + 标签配对
```

**证治分类原文核验**（规则 14）：从教材提取每证型的主症／证机概要／治法／代表方后，先用 `ocr_check.py` 扫错字，
再用 `search_textbooks.py --track 中医 --keyword "<方名或症状片段>"` 回搜教材原文逐字定位。
命中失败或 OCR 存疑处标注「[OCR 存疑]」，不得擅改。

另需逐项自查 `references/quality-checklist.md` 的「OneNote 版专属检查」与「**中医内科学讲义体例检查**」。
