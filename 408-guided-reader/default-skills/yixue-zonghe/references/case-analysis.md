# 病案分析框架

> 供「病案分析」功能使用。输入病案后按本框架逐层推进，输出结构化分析报告。

---

## 一、标准工作流程（六步法）

```
病案输入 → ①四诊信息提取 → ②辨证分析 → ③病因病机推演 → ④治法确立 → ⑤方药拟定 → ⑥经典文献对照
```

### 第 1 步：四诊信息提取（结构化表格）

| 四诊 | 提取要点 | 病案中的信息 |
|------|---------|------------|
| **望诊** | 神色、形态、舌质、舌苔、排泄物 | … |
| **闻诊** | 声音、气味 | … |
| **问诊** | 主诉、现病史、寒热、汗、头身、二便、饮食口味、睡眠、经带 | … |
| **切诊** | 脉象（寸关尺、浮沉迟数）、按诊（腹诊、肌肤） | … |

**规则：**
- 病案未记载的项目明确标注「未载」，不得臆造
- 优先标记**具有辨证决定意义**的信息（如舌红苔黄腻→湿热）
- 十问歌逐项核对：一问寒热二问汗，三问头身四问便……

### 第 2 步：辨证分析（八纲 + 脏腑 + 病性 + 六经定位）

1. **八纲定位**：表里、寒热、虚实、阴阳
2. **病位**：脏腑经络定位（结合五行生克、脏腑关联）
3. **病性**：六淫、痰饮、瘀血、气滞、食积、虚实夹杂
4. **六经定位（倪师体系，必出）**：按《伤寒论》六经开阖枢判定病属何经，与八纲互参。诊断公式与分型速查见 `倪海厦体系/references/distilled/01-six-meridian-formulas.md`，8 个诊断公式汇总：

   | 经 | 辨证公式（满足即成立） | 代表方 |
   |----|----------------------|--------|
   | 太阳 | 脉浮 + 头项强痛 + 恶寒 | 桂枝汤/麻黄汤 |
   | 阳明 | 身热 + 汗自出 + 不恶寒反恶热 + 脉大 | 白虎汤/承气汤 |
   | 少阳 | 口苦 + 咽干 + 目眩 + 往来寒热 + 胸胁苦满 + 呕 | 小柴胡汤 |
   | 太阴 | 腹满 + 呕吐 + 食不下 + 自利 + 时腹自痛 + 不口渴 | 四逆辈/理中汤 |
   | 少阴（寒化） | 脉微细 + 但欲寐 + 恶寒蜷卧 + 手足逆冷 | 四逆汤/真武汤 |
   | 少阴（热化） | 脉细数 + 心烦不得卧 + 舌红少苔 | 黄连阿胶汤 |
   | 厥阴 | 消渴 + 气上撞心 + 心中疼热 + 饥而不欲食 + 寒热错杂 | 乌梅丸/当归四逆汤 |
   | 合病/并病 | 两经或三经症状并见 | 见合病速查表 |

   **快速辨证流程图**（节选自 `01-six-meridian-formulas.md`）：
   ```
   患者就诊
       │
       ├─ 有恶寒？──┬─ YES ─→ 脉浮？──┬─ YES ─→ 有汗？──┬─ YES ─→ 太阳中风（桂枝汤）
       │             │                 │                 └─ NO ──→ 太阳伤寒（麻黄汤）
       │             │                 └─ NO ──→ 脉沉？──┬─ YES ─→ 少阴兼表（麻附辛汤）
       │             └─ NO ──→ 恶热？──┬─ YES ─→ 阳明病（白虎/承气）
       │                              └─ NO ──→ 往来寒热？── YES ─→ 少阳病（小柴胡汤）
       ├─ 腹满+自利+不渴？──→ 太阴病（四逆辈/理中汤）
       ├─ 脉微细+但欲寐？──┬─ 舌淡苔白 → 少阴寒化（四逆汤/真武汤）
       │                    └─ 舌红少苔 → 少阴热化（黄连阿胶汤）
       └─ 寒热错杂+饥不欲食？──→ 厥阴病（乌梅丸/当归四逆汤）
   ```

   > 引用规则：六经结论必须落到具体分型与代表方，并按倪师铁律核对禁忌（如太阳病有汗/无汗、少阳三禁、少阴不可发汗）。

5. **辨证结论**：使用标准格式——

```
**辨证：{证型名}（{病机概述}）**
病位：{脏腑/经络}
病性：{虚实寒热}
六经归属：{太阳/阳明/少阳/太阴/少阴/厥阴/合病}（倪师体系）
```

### 第 3 步：病因病机推演

用箭头图呈现病机演变链条：

```
{病因} → {第一层病机} → {第二层病机} → {当前主症病机}
                    ↘ {兼夹病机} → {兼症}
```

**六经传变路径分析（倪师体系，必出）**：在病因病机推演中追加六经传变判断，明确标注当前病在何经、由何经传入、是否会继续传变。正传与变传路径见 `01-six-meridian-formulas.md` 末段「传变规律」：

- **正传（由表入里）**：
  ```
  太阳 → 阳明（阳明居中土，万物所归，无所复传——病到阳明即停住）
  太阳 → 少阳 → 太阴 → 少阴 → 厥阴
  ```
- **合病/并病（同时或先后）**：按合病速查表标注（如太阳少阳合病→柴胡桂枝汤、太阳阳明合病→大青龙汤/葛根芩连汤）。
- **误治传变与急救**：标注有无误治史（如太阳误下→利不止→理中汤救逆；少阴误汗→亡阳→四逆汤+艾灸关元神阙）。
- **传变预警**：
  - 太阳病超过 5-7 天未愈 → 注意是否传入少阳（口苦、咽干、胸胁满）
  - 太阴病日久 → 脉由沉迟转为沉微、精神由倦怠转为萎靡 → 当从少阴论治
- **欲解时**：标注该经欲解时辰（如太阴欲解于亥至丑、少阴子至寅上、厥阴丑至卯上），用于推断预后与服药时机。

输出格式：

```
**六经传变**：{原发经} → {当前经}（{传变类型：正传/合病/并病/误治传变}）
预后：{欲解时辰/传变趋势}
```

### 第 4 步：治法确立

- **总治则**：正治反治、标本缓急、扶正祛邪、调整阴阳
- **具体治法**：与证型一一对应（如「肝郁脾虚→疏肝健脾」）
- **倪师"先辨阴阳、再选方"原则（必出）**：在确立治法前，先按倪师铁律判定阴阳大局，再据此定方剂方向：
  1. **先辨阴阳存亡**（危重症第一关）：阳气存亡决定生死。阳气将绝（脉微欲绝、四逆冷汗、但欲寐）→ 立即回阳救逆，参附四逆辈当机立断，不可迟疑。
  2. **再辨阴阳表里虚实寒热**：定八纲大局 → 决定汗、和、下、温、清、补、消八法的取舍。如：
     - 太阳表证（阳）→ 汗法（桂枝汤解肌 / 麻黄汤发汗）
     - 阳明里热（阳）→ 清下法（白虎汤清 / 承气汤下）
     - 少阳半表半里（阳）→ 和法（小柴胡汤——禁汗禁下禁吐）
     - 太阴里虚寒（阴）→ 温中（理中汤/四逆辈）
     - 少阴里虚寒（阴）→ 回阳救逆（四逆汤/真武汤）
     - 厥阴寒热错杂（阴）→ 寒温并用（乌梅丸）
  3. **选方优先级**：倪师铁律——
     - 见桂枝汤证/麻黄汤证兼表阳虚（手足烦热、腹中痛）→ 先用小建中汤
     - 见脉结代 → 先用炙甘草汤补足里阴，再治他病
     - 太阳表未解 → 绝对不可攻里（先解表再攻里）
     - 有汗用麻黄/无汗用桂枝/少阳用汗下/少阴用汗 → 均为亡阳危证，须立即纠正

### 第 5 步：方药拟定

- **主方**：首选经方/时方，注明出处
- **方义分析**：君臣佐使逐味拆解（见 prescription-guide.md）
- **加减**：针对兼症的具体加减法
- **调护**：饮食宜忌、起居建议
- **倪师临床剂量档位（必出，见 `distilled/05-clinical-dose-quickref.md` 与 `06-clinical-dose-c99.md`）**：经方主方在"原方剂量→临床剂量"换算之外，必须并列倪师临床常用剂量档位。三列对照规范见 `prescription-guide.md` 第二节。要点：
  - 优先取倪师源文件口述剂量（标〔口述〕）；无口述按「原方一两=临床一钱」换算（标〔换算〕，台湾剂量 1 钱≈3.75g）。
  - 体格档位：壮汉（桂枝 5 钱）、成人（3 钱）、瘦子（2 钱）、小儿（半钱-1 钱）。
  - 必须标注炮制（生附子 vs 炮附子）、煎服法（如"九碗煮三碗，日三服"）与配伍禁忌（十八反十九畏）。
- **经方条文卡片（必出）**：凡用经方，必附条文卡片，引用《伤寒论》/《金匮要略》原文。卡片规范见 `prescription-guide.md` 第一节第 2 层。格式：

  ```
  > **【{方名} · {书名·第X条}】**
  > 「{原文}」
  > {原方组成与剂量}
  > {煎服法}
  > 倪师临床：{倪师三行——病机一句话 + 主证一句 + 关键剂量口述}
  ```

  条文获取方法：

  ```bash
  python scripts/search_textbooks.py --keyword "{方名}主之" --category 伤寒论,金匮要略
  ```

### 第 6 步：经典文献对照（本知识库特色）

用检索脚本查找经典依据，引用原文佐证辨证与选方：

```bash
python scripts/search_textbooks.py --keyword "{核心证候或方名}" --category 金匮要略,伤寒论
```

输出格式（条文卡片，借鉴经方派风格）：

> **【经典依据】**《金匮要略·胸痹心痛短气病脉证治》：「师曰：夫脉当取太过不及，阳微阴弦，即胸痹而痛，所以然者，责其极虚也。」

**三库对照（必出）**：将辨证与选方的依据在四个知识库中交叉印证，按以下表格输出。如三方一致，置信度最高；如出现分歧，明确标注分歧点与各库立场。

| 维度 | 现代教材（基线） | 倪海厦体系（经方派） | 石学敏体系（针灸派） | 蒸馏专家库（如有） |
|------|-----------------|---------------------|---------------------|-------------------|
| 病机定位 | {中医内科学/诊断学定位} | {六经归属 + 倪师口述} | {经络辨证 + 病候} | {专家体系结论} |
| 治法 | {教材标准治法} | {倪师"先辨阴阳再选方"结论} | {治神守气 + 针刺量学} | {专家治法} |
| 主方/主穴 | {教材主方} | {经方 + 三列剂量} | {主穴+配穴+量学参数} | {专家主方} |
| 经典依据 | {教材引用条文} | {伤寒/金匮条文 + 倪师讲解} | {灵枢/素问原文 + 石师新解} | {专家引用} |
| 分歧/补充 | — | {倪师与教材不同处} | {石师与教材不同处} | {专家增补} |

## 二、疑难病案的处理规则

| 情形 | 处理方式 |
|------|---------|
| 四诊信息不全 | 列出「需要补充的问诊清单」，按最可能证型给出试探性分析 |
| 证候矛盾（寒热错杂） | 分清标本、先后、主次；考虑上热下寒（半夏泻心汤类）、表寒里饮（小青龙汤类）等格局 |
| 多证并存 | 主证定主方，兼证作加减；避免多方堆砌 |
| 久病虚实夹杂 | 遵循「久病及肾」「久病入络」思路，考虑扶正与祛邪比例 |
| 倪海厦经验参考 | 危重症先辨阴阳（阳气存亡），参附四逆辈当机立断 |

## 三、病案来源与练习模式

1. **用户提交病案**：按六步法完整分析
2. **知识库取案**：从医案医话类古籍（64 部）提取真实医案做示范分析
   ```bash
   python scripts/search_textbooks.py --keyword "{病名}医案" --category 医案医话
   ```
3. **教学出案**（配合模拟题功能）：从中医内科学教材提取病案，隐去治法方药作为练习题，附标准答案

## 四、输出质量标准

- 每一步都必须有**证据链**：结论 ← 四诊依据 ←（缺一不可）
- 辨证结论必须落到**标准证型名**（与中医诊断学教材一致）
- 经典引用必须注明**书名+篇名**，原文用引号
- 方药剂量给出**现代常用量**并注明「原方剂量另列」，毒性药物必须标注（见 SKILL.md 通用规则）
- 不确定处明确写「本案亦可从{X}证考虑，鉴别点在于{Y}」，禁止武断
