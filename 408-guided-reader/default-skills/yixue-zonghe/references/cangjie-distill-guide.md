# 仓颉蒸馏操作指南（医学教材适配版）

> 供 yixue-zonghe skill 用仓颉认知植入术蒸馏医学专家/教材时使用。
> 仓颉原版见 `仓颉/SKILL.md`（人物蒸馏7步流程），本指南是其在医学场景下的适配版。
> 适用：用户上传某医学专家著作/讲义/医案集，或某版医学教材，希望蒸馏成可调用的专家 Skill 时触发。
> 触发词：「蒸馏XX」「用仓颉提取XX」「做个XX的思维Skill」「蒸馏教材」「教材蒸馏」。

---

## 一、两种蒸馏类型

收到素材后，先在 Step 1 判定蒸馏类型，二者适配点不同：

| 类型 | 素材形态 | 直接复用 vs 适配 | 输出角色内核 |
|------|---------|----------------|-------------|
| **A. 人物蒸馏** | 某专家的著作/讲座/访谈/医案（如《倪海厦人纪系列》《石学敏针灸全集》） | **直接复用仓颉原版7步流程**（见 `仓颉/SKILL.md`） | 第一人称"我"——专家本人 |
| **B. 教材蒸馏** | 某版医学教材/方剂学/腧穴学（如《中医内科学》第X版、《针灸学》某教材） | **本指南适配版**（见下文第二节） | 第一人称"我"——教材主编团队 |

**判定要点**：
- 素材以"人"为中心（专著/讲座/医案集，含个人观点与失败案例）→ A 类
- 素材以"学科"为中心（系统性教材，章节按学科体例编排）→ B 类
- 素材兼有（如《石学敏针灸全集》既是教材又是个人学术体系）→ 按 A 类蒸馏（个人学术思想优先，教材体例退居知识图谱）

> 已有先例：`倪海厦体系/`（A 类，专家蒸馏）、`石学敏体系/`（A 类，专家+教材混合，主按 A 类）、`仓颉/examples/paul-graham-perspective/`（A 类，纯人物）。

## 二、教材蒸馏适配要点（B 类专用）

仓颉原版 7 级清单（L1-L7）在教材场景下的语义映射：

| 仓颉原版 | 教材蒸馏适配语义 | 教材中的对应物 |
|---------|----------------|---------------|
| **L1 信念形成故事**（"我信X是因为经历了Y"） | **学术观点形成依据**（"本教材持X观点，依据是Y临床研究/古籍深读"） | 绪言/前言中主编学术思想自述；某观点后附的临床数据/古籍引证 |
| **L2 真实决策复盘**（做了什么+当时想什么+事后反思） | **典型病案决策**（某病案选某方/某穴+推理依据+疗效反思） | 教材医案章节/按语/附案 |
| **L3 失败/错误承认**（本人承认） | **学术修正**（前版观点/治法的修正与原因） | 修订版前言中的"本版修订要点"；按语中"旧法不足，故改良为..." |
| **L4 内在矛盾暴露**（前后不一致） | **学术争议**（本教材内部未调和的张力，或与主流的不同声音） | 兼收并蓄的不同学说；"各家说法不一，本教材取..." |
| **L5 认知边界声明**（"这不是我的领域"） | **学术适用边界**（本教材明确的不适用范围/病种限制/证据强度声明） | "本病尚无有效疗法"、"此法限于..."、"证据等级为..." |
| **L6 思维习惯案例**（反复出现的分析模式） | **学术方法论**（主编反复使用的辨证/选方/取穴思路） | 各章节反复出现的辨证框架（如"先辨阴阳再选方""治神守气首位"） |
| **L7 通用观点/金句** | **学科通用知识**（无独特形成故事则跳过） | 教材正文中的标准定义、常规治法——**不入 SKILL.md** |

**适配铁律**：
1. 教材蒸馏不是"把教材目录搬进 SKILL.md"——目录式的通用知识不入角色内核，只入 `references/research/04-knowledge-map.md` 作导航
2. 入 SKILL.md 的必须是"主编为什么这样编排/为什么持此观点"的**形成故事+修正路径+争议张力**，不是结论本身
3. 教材体例下，绪言/前言/按语/修订说明/医案附按是高价值素材（含第一人称口吻），优先精读；正文章节是知识图谱素材，扫描即可

## 三、蒸馏产出目录结构规范

### 3.1 产出根目录

A 类（人物蒸馏）：

```
[专家名]-perspective/           # 如 nihaixia-perspective/、shixuemin-perspective/
├── SKILL.md                     # 角色内核（必出）
└── references/
    ├── research/                # 调研留痕（必出）
    │   ├── 01-sources.md        # 来源清单（一手/二手+可信度）
    │   ├── 02-extraction-notes.md # 提取记录（按7级清单标注优先级/出处）
    │   ├── 03-key-quotes.md     # 关键原文引用（只保留被引用段落）
    │   ├── 04-knowledge-map.md  # 教材/全集知识图谱（页码/章节导航，如有 PDF）
    │   └── (05-decisions.md 等按需扩展)
    └── distilled/               # 速查精华（可选，量大时强烈建议）
        ├── README.md            # distilled 目录导航
        └── 01-{主题}-quickref.md  # 按主题蒸馏的速查手册
```

B 类（教材蒸馏）：

```
[教材名]-textbook-perspective/   # 如 zhongyi-neikexue-textbook-perspective/
├── SKILL.md                     # 主编团队角色内核（必出）
└── references/
    ├── research/
    │   ├── 01-sources.md        # 教材版本+主编+精读章节
    │   ├── 02-extraction-notes.md # L1-L7 适配版提取记录
    │   ├── 03-key-quotes.md     # 绪言/前言/按语关键原文
    │   └── 04-knowledge-map.md  # 教材全书章节图谱（页码导航）
    └── distilled/               # 速查（如辨证速查/方剂速查）
        └── 01-{主题}-quickref.md
```

### 3.2 蒸馏产出在 yixue-zonghe skill 中的位置

蒸馏产出的专家体系**统一放在 skill 根目录下**（与 `倪海厦体系/`、`石学敏体系/` 平级）：

```
yixue-zonghe_extracted/
├── 倪海厦体系/                  # 已集成
├── 石学敏体系/                  # 已集成
├── {新蒸馏专家名}体系/          # 新蒸馏产出
└── 蒸馏产出/                    # 蒸馏中间产物/草稿目录
```

蒸馏完成后，在 `references/` 下同步创建对应的 `references/{专家名}-integration.md` 运行时摘要（参考 `nihaixia-integration.md` / `shixuemin-integration.md` 的体例）。

## 四、动态发现机制说明（Step 0 前置扫描）

> **新增**：仓颉原版从 Step 1 开始，本指南在 Step 1 之前加 Step 0——前置扫描，动态发现可用素材。

### Step 0：前置扫描（动态发现）

收到蒸馏请求后，**先扫描 skill 根目录与子目录，发现现有素材**，再决定从哪里取材：

```bash
# 1. 扫描 skill 根目录下已有哪些专家体系
# 工具：Glob（不是 shell ls）
Glob "yixue-zonghe_extracted/*/"
# 返回：倪海厦体系/ 石学敏体系/ 仓颉/ 蒸馏产出/ 中医教材/ 西医教材/ ...

# 2. 扫描素材文件
Glob "yixue-zonghe_extracted/中医教材/*.pdf"  # 或 *.txt *.md
Glob "yixue-zonghe_extracted/西医教材/*.pdf"

# 3. 扫描用户当前上传的素材
# 用户上传文件后，确认路径并读取
```

**Step 0 的三个判断**：

1. **素材在 skill 内**（如 `中医教材/` 下的 PDF）→ 直接读，进入 Step 1
2. **素材在 skill 外**（用户本地路径）→ 用 Read/WebFetch 读取，进入 Step 1
3. **素材不足**（用户只说人名没给素材）→ 用 WebSearch 采集（见 `仓颉/SKILL.md` Step 2B），但医学专家优先建议用户提供一手素材，避免网搜拼凑

**Step 0 的产出**：在 `references/research/01-sources.md` 中记录"扫描发现的素材清单"+ 各素材的初步价值评估（★~★★★），作为 Step 2 精读的优先级依据。

## 五、专家能力匹配规则表

蒸馏产出后，**自动判定**新专家体系适合调用 yixue-zonghe skill 的哪些功能。下表为能力匹配规则：

| 能力维度 | 匹配信号（蒸馏产出中出现的关键词/章节） | 匹配到的 yixue-zonghe 功能 |
|---------|--------------------------------------|---------------------------|
| **经方辨证** | 伤寒论/金匮要略/六经辨证/方剂剂量/经方条文 | 学习（伤寒/金匮）、病案分析、处方讲解、模拟题 |
| **方剂学** | 方剂学教材/类方/君臣佐使/方剂鉴别 | 学习（方剂）、处方讲解、模拟题 |
| **中药学** | 本草经/中药学教材/药性论/配伍禁忌 | 学习（中药）、处方讲解 |
| **针灸腧穴** | 针灸学/经络腧穴/五输穴/特定穴 | 针灸功能、学习（针灸）、模拟题 |
| **针刺手法** | 刺灸法/针刺手法/补泻/量学参数 | 针灸功能、病案分析（针灸处方） |
| **中医内科** | 中医内科学/病证分型/辨证论治 | 学习（内科）、病案分析、模拟题 |
| **西医基础医学** | 生理学/病理生理学/生物化学/解剖学/组织学与胚胎学/医学遗传学/医学生物学 | 西医学习、讲义、出题（**视频课程蒸馏亦归此类**） |
| **西医内科** | 内科学教材/诊断与鉴别诊断 | 西医学习、病案分析（西医） |
| **西医药学** | 药理学/药物分类/作用机制/不良反应 | 西药讲解、出题 |
| **医案集** | 医案/临床决策/疗效反思 | 病案分析、模拟题（医案题） |
| **中医基础** | 中基/阴阳五行/脏腑经络/气血津液 | 学习（中基） |
| **诊断学** | 中医诊断/四诊/辨证/西医诊断学 | 学习（诊断）、病案分析 |

**匹配规则**：
1. 蒸馏产出后，扫描 SKILL.md 与 `references/distilled/` 下的关键词，按上表匹配
2. 一位专家可匹配多个功能（如倪师匹配经方+针灸+病案+处方+模拟题；石师匹配针灸+病案+学习+模拟题）
3. 匹配结果写入 `references/{专家名}-integration.md` 的"各功能调用指引"段
4. **不匹配的功能**：新专家不得调用——如纯经方专家不调用西医功能；纯内科专家不调用针灸功能

## 六、质量自检流程（quality_check.py 11 项）

蒸馏产出 SKILL.md 后，**必须运行** `仓颉/scripts/quality_check.py` 自检：

```bash
python 仓颉/scripts/quality_check.py "{新专家体系路径}/SKILL.md"
```

自检共 **11 项**（6 项女娲基础项 + 5 项仓颉升级项）：

### 6.1 女娲基础项（6 项）

| # | 检查项 | 通过标准 | 教材蒸馏适配说明 |
|---|--------|---------|----------------|
| 1 | **心智模型数量** | 3-7 个（`### 模型N` 或 "我看问题的方式" section 下的 `###` 子段） | 教材蒸馏：主编学术方法论≥3 个，避免拼凑通用方法论 |
| 2 | **模型局限性** | 内容含"局限/失效/不适用/盲区/limitation"等词 | 教材蒸馏：必须标学术适用边界（病种/证据强度限制） |
| 3 | **表达DNA辨识度** | 表达DNA/我说话的方式 section 存在，且特征词≥3 项 | 教材蒸馏：主编团队的表达偏好（引经据典/量学参数/学术口吻） |
| 4 | **诚实边界** | ≥3 条（"我明确不懂/Honest Boundary" section） | 教材蒸馏：学术适用边界≥3 条（病种/证据/技法限制） |
| 5 | **内在张力** | ≥2 处（"张力/矛盾/tension/一方面...另一方面"） | 教材蒸馏：学术争议≥2 处（崇古vs破古/个性vs共性等） |
| 6 | **一手来源占比** | >50%（来源 section 中"一手/primary/本人著作/原始"占比） | 教材蒸馏：教材本体为一手，按语/医案为一手，他人转述为二手 |

### 6.2 仓颉升级项（5 项）

| # | 检查项 | 通过标准 | 教材蒸馏适配说明 |
|---|--------|---------|----------------|
| 7 | **触发条件** | ≥3 个模型有触发条件（`**触发条件**` 或"什么时候用/什么情况下.*激活"） | 教材蒸馏：每条学术方法论要有触发场景（如"遇到X病时，先..."） |
| 8 | **推理步骤** | ≥2 处结构化步骤（`**推理步骤**`）或 ≥6 处编号步骤 | 教材蒸馏：辨证/选方/取穴的分步推理≥2 处 |
| 9 | **推理示例链** | ≥2 个完整推理链（`### 示例N` 或 "问题→推理→结论"配对） | 教材蒸馏：典型病案的辨证推理示例≥2 个 |
| 10 | **反模式护栏** | ≥2 处"护栏/guardrail/反模式检查/扫描.*反模式"等标记 | 教材蒸馏：学术红线（如"不得超出证据强度夸大疗效"）≥2 处 |
| 11 | **Harness Engine** | 有"Harness Engine/运行时推理/推理引擎/问题路由/Step 1...路由"等 | 教材蒸馏：必须有运行时调用机制（不要求写 Step 1/2/3 详流程） |

### 6.3 自检结果处理

- **11/11 通过**：🎉 全部通过，可以交付
- **9-10/11 通过**：⚠️ 基本通过，建议修复不通过项后交付
- **≤8/11 通过**：❌ 多项不通过，回到 Step 3（`仓颉/SKILL.md` 的"提取认知上下文"）迭代

### 6.4 教材蒸馏的额外自检（非脚本项，人工核对）

- [ ] 是否区分了"学术观点形成依据"（L1）vs 学科通用知识（L7 跳过）？通用知识未入 SKILL.md？
- [ ] 学术修正（L3）是否是教材修订版前言/按语中**主编团队自己承认**的？非外部推断？
- [ ] 学术争议（L4）是否如实保留不调和？未为"统一口径"而抹平？
- [ ] 医案决策（L2）是否含"事后反思"？光有事实没反思的不入？
- [ ] 是否标注了证据强度？（如"系统评价纳入研究少，论证强度受影响"）
- [ ] 学术适用边界（L5）是否具体到病种/证据等级/技法限制？不是泛泛的"我不懂"？
- [ ] 表达DNA是否≤3偏好+3禁忌？未做详细句式分析？

## 七、完整流程速查（教材蒸馏适配版）

```
Step 0：前置扫描（本指南新增）
  ├─ Glob 扫描 skill 内已有素材
  ├─ Read/WebFetch 读取外部素材
  └─ 写 01-sources.md（素材清单+价值评估）
       │
Step 1：确认对象与素材（仓颉原版）
  ├─ 判定 A 类（人物）vs B 类（教材）
  └─ 确认聚焦方向（全面/经方/针灸/内科/...）
       │
Step 2：消化素材→结构化调研文件（仓颉原版+本指南适配）
  ├─ 7 级清单扫描（L1-L7）
  ├─ 教材蒸馏按第二节语义映射
  ├─ 写 02-extraction-notes.md（标注优先级/出处）
  └─ 写 03-key-quotes.md（只保留被引用段落）
       │
Step 3：提取认知上下文（仓颉原版+本指南适配）
  ├─ 3.1 信念/学术观点形成依据（5-7条，每条有形成故事）
  ├─ 3.2 真实决策/典型病案决策（3-5个，含事后反思）
  ├─ 3.3 失败修正/学术修正（2-3个，主编自认）
  ├─ 3.4 内在矛盾/学术争议（2-3对，保留不调和）
  ├─ 3.5 认知边界/学术适用边界（≥3条）
  ├─ 3.6 思维习惯/学术方法论（3-7个，第一人称）
  └─ 3.7 表达DNA（3偏好+3禁忌）
       │
Step 4：展示摘要，等用户确认（仓颉原版）
       │
Step 5：组装 SKILL.md（仓颉原版，按 skill-template.md）
  └─ 同时写 04-knowledge-map.md（如有PDF/全集）
       │
Step 6：质量自检（本指南第6节11项+人工核对7项）
  ├─ 运行 quality_check.py
  └─ 人工核对教材蒸馏额外项
       │
Step 7：交付（仓颉原版+本指南增量）
  ├─ 写 references/{专家名}-integration.md 运行时摘要
  └─ 按本指南第五节匹配 yixue-zonghe 功能调用范围
```
