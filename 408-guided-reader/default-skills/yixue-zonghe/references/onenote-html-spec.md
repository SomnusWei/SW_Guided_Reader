# OneNote 适配讲义 HTML 规范

> 本文件是 `SKILL.md` 功能二「讲义制作」的交付格式规范。
> **讲义默认交付 OneNote 适配的 HTML，不输出 PDF。**
> 转换由 `scripts/to_onenote.py` 自动完成；本文件说明"为什么""转成什么样""怎么验收"。

---

## 一、为什么默认 OneNote 适配

| 原因 | 说明 |
|------|------|
| 落地场景 | 医学讲义的实际使用方式是**导入 OneNote 做长期笔记与批注**，而不是打印或阅读一次性 PDF |
| PDF 的缺点 | 不可编辑、不可批注、手机上难读、体积大、后续无法增量更新 |
| 网页版的缺点 | 样式集中在 `<style>` 块并由 class 驱动，还依赖 `position:sticky` 侧栏与 `linear-gradient`。OneNote 粘贴网页内容时会**优化掉**大部分样式表声明与布局属性（浮动、粘性、定位） |
| OneNote 版的优势 | 样式**全部内联**、布局**改由嵌套表格承担**后，表格结构、单元格底色、分色标注能被 OneNote 保留；同时仍是合法网页，可在浏览器阅读与打印 |

> **诚实边界**：OneNote 对粘贴内容始终会做"优化"，无法保证 100% 还原。**稳定保留**的是表格结构、
> `bgcolor` 底色、字体颜色与字号、加粗；**可能丢失**的是精细间距、圆角、阴影、自定义字体。
> 这正是本规范要把"卡片"降级为"双格表格"、把"侧栏"降级为"文内表格"的原因——
> 用 OneNote 能懂的结构，换取尽可能高的保真度。

**结论**：讲义制作 = 生成讲义 HTML → 转 OneNote 适配版 → 质检 → 交付。
**不再有"PDF 导出"这一步。**

---

## 二、交付物命名与并存策略

```
<skill产出目录>/
├── <讲义名>.html                  ← 网页版（编写底稿，浏览器阅读用）
└── <讲义名>_OneNote版.html         ← ★ 默认交付物（OneNote 导入用）
```

- **默认只交付 `_OneNote版.html`**，并在回复中直接给出链接
- 网页版底稿同时保留（它是转换的输入，也是浏览器阅读的版本）；用户只要 OneNote 版时，可只交付后者
- 一份讲义通常一页；若内容过长（如超过 3 万字），建议按"一节一页"拆成多个 HTML，每页各自转 OneNote 版

## 三、转换链路

```bash
# 1) 编写网页版讲义（class 驱动，样式集中在 <style> 或 templates/lecture-style.css）
#    产物：<讲义名>.html

# 2) 转 OneNote 适配版
<python> scripts/to_onenote.py \
    --src "<讲义名>.html" \
    --out "<讲义名>_OneNote版.html" \
    --primary "#0f6b6b" \
    --toc-meta "《生理学》（第10版）第一章 绪论<br>专家体系：刘忠保·生理学<br>素材覆盖 P01（1.5 小时）" \
    --check
```

### 参数

| 参数 | 必填 | 说明 |
|------|:---:|------|
| `--src` | ✔ | 输入：网页版讲义 HTML |
| `--out` | ✔ | 输出：OneNote 适配版 HTML |
| `--primary` | | 主题色，默认 `#0f6b6b`。**只需给这一个颜色**，深色、卡片底纹、描边、小结底色全部自动派生 |
| `--primary-dark` | | 主题深色，默认自动派生（primary × 0.70） |
| `--accent` | | 章节编号 `［目标］` 前缀色，默认 `#b8860b`（金棕） |
| `--title` | | 输出文件 `<title>`，默认取源 `<title>` 加"（OneNote 版）" |
| `--toc-meta` | | 文内目录的说明行（用 `<br>` 分隔）；默认从源文件侧栏 `.meta` 自动提取 |
| `--note` | | 封面下方的说明行；传空串可去掉 |
| `--check` | | 转换后自检：class/变量/渐变残留、标签配对，并打印结构统计 |

**主题色推荐值**：中医青绿 `#0f6b6b`、西医蓝 `#1e4d8c`、倪海厦体系棕金 `#8a5b00`、金匮/经方 `#7a4b00`。

## 四、构件对照表（网页版 → OneNote 版）

| 网页版构件 | OneNote 版实现 |
|------------|----------------|
| `--primary` 等 CSS 变量 | 全部解析为字面色值，**不保留任何 `var()`** |
| 固定侧栏目录（`position:sticky`） | **文内目录表格**（`bgcolor` 底纹 + 三級条目） |
| 渐变封面（`linear-gradient`） | 单格 `bgcolor` 表格，标题 23pt 白色粗体；封面内 `<strong>` 强制反白 |
| 章节标题 `h2.sec` + `span.num` | `<h2>` + `<strong style="color:{accent}">［目标］</strong>　标题`，**其后追加一条 3px 分隔条表格** |
| `h3` / `h4` | 内联样式 + `<span style="color:{primary}">▍</span>` 前缀 |
| 卡片 `.card-*`（`border-left` 色条 + 圆角） | **双格表格**：左格 `width="6"` 纯色条 + 右格内容格；表头为嵌套小表（徽标格 + 标题格） |
| 引文 `.q`（CSS `::before/::after` 生成「」） | **白底虚线表格**，`「」` 改为实体字符包住整段 |
| 口诀大字 `.big` | 居中表格格，12.5pt 粗体；`<br>` 拆成多个 `<p>` |
| 考点边界 `.exam-grid` | 单行两格表格，红/灰配色 |
| 居中提示块（inline `background`） | `bgcolor` 居中表格格 |
| 小结框 `.summary-box` | 2px 主题色边框表格格，标题 12pt |
| 数据表 `th/td`（class 驱动） | `<table border="1">` + `th/td` 全内联样式 + **隔行底色 `#f7fafd`** |
| `code` | `<span style="font-family:Consolas…">` |
| 时间戳 `.ts` | Consolas 高亮 span（米色底 + 棕字） |
| `@page` | 补 `@page{size:A4;margin:1.6cm;}` |
| 动画 / 过渡 / 阴影 / 圆角 | **全部移除** |

### 语义卡片固定配色（与主题色无关，全库统一）

| 卡片 | 色条 / 徽标 | 底纹 | 描边 | 标题字色 | 徽标文字 |
|------|------------|------|------|----------|----------|
| `.card-textbook` 教材基线 | 主题色 | 主题 4% 淡染 | 主题 22% 淡染 | 主题深色 | `教材基线` |
| `.card-liu` 专家 | `#b8860b` | `#fff8ec` | `#e8b96a` | `#7a4b00` | 专家名（如 `刘忠保`） |
| `.card-mnemonic` 记忆框架 | `#6b4fbb` | `#f3f0fb` | `#cfc4ee` | `#4b338e` | `记忆框架` |
| `.card-boundary` 考点边界 | `#a83232` | `#fdf2f2` | `#e7bcbc` | `#a83232` | `考点边界` |
| `.card-clinic` 临床联系 | `#1a6b3c` | `#eef8f1` | `#bfe0cc` | `#1a6b3c` | `临床联系` |
| `.card-note` 提示 / 说明 | `#2a6099` | `#eef4fb` | `#c4d8ee` | `#1f4a76` | `提示`／`使用说明` |

> 徽标文字直接取源卡片 `.hd > .badge` 的文本，脚本不硬编码，新增卡片类型无需改脚本。

### 字号规范（一律 pt）

| 用途 | 字号 |
|------|------|
| 正文 / `body` | 11pt |
| 封面主标题 | 23pt |
| 封面副标题 | 12.5pt |
| 封面来源 / 标签 | 9.5pt / 9pt |
| `h2` 章节标题 | 17pt |
| `h3` | 13.5pt |
| `h4` | 11.5pt |
| 卡片徽标 / 卡片标题 | 9.5pt / 10.5pt |
| 口诀大字 | 12.5pt |
| 数据表 `th/td` | 10pt |
| 时间戳 span | 9pt |
| `code` span | 9.5pt |

> 源文件里的 `px` 字号由脚本按 `px × 0.75 = pt` 自动换算。

## 五、目录规则

源侧栏 `<ol>` 的三类 `<li>` 映射为文内目录的三个层级：

| 源写法 | 文内目录渲染 |
|--------|--------------|
| `<li class="grp">第一节 · 物质转运</li>` | 分组标题：9.5pt 主题色粗体，无项目符号 |
| `<li><a>一、……</a></li>` | 一级：10pt 灰字，前缀 `· ` |
| `<li class="l2"><a>（一）……</a></li>` | 二级：10pt 灰字 + `padding-left:14px`，前缀 `· ` |

目录表头为「目 录」11pt 主题深色 + `letter-spacing:2px`，下方接 `--toc-meta` 说明行（9pt）。

## 六、质检项（OneNote 版专属）

除 `references/quality-checklist.md` 的通用项外，OneNote 版**必须**通过：

| # | 检查项 | 判据 |
|---|--------|------|
| 1 | 无 `class` 属性 | `class="` 计数 = 0 |
| 2 | 无 CSS 变量 | `var(--` 计数 = 0 |
| 3 | 无渐变 | `linear-gradient` 计数 = 0 |
| 4 | 无浮动 / 粘性 | `position:sticky`、`position:fixed` 计数 = 0 |
| 5 | 无伪元素 | `::before`、`::after` 计数 = 0 |
| 6 | 无 px 字号 | `px"` 计数 = 0（正文中不应再出现 px 字号声明） |
| 7 | 标签配对 | `table/tr/td/th/p/span/ul/ol/li/h2/h3/h4` 开闭计数全部相等 |
| 8 | 结构统计一致 | `card / quote / h2 / h3 / h4 / table / big / flow / exam / summary / footer` 各项数量与网页版目视核对一致 |
| 9 | 内容零丢失 | 源文逐句在产出中检索得到（唯一允许的差异是被替换掉的侧栏目录） |
| 10 | 无新增内容 | 产出中不应出现源文没有的实质内容 |
| 11 | 目录非空 | 脚本报告"未解析到目录条目"即为失败（源侧栏结构不符） |
| 12 | 编码 | UTF-8，无乱码 |

第 1–7、11 项由 `to_onenote.py --check` 自动完成；第 8–10 项需用脚本逐句核对（见下方命令）。

### 内容零丢失核对（建议固化）

```python
# 源文按句切分，逐句在产出中检索；同时反向检查产出有无新增句
DROP = r'[［］「」·▍\s]'
src_plain = 去标签后的源文纯文本
out_plain = 去标签后的产出纯文本
# 正句：源句子去掉 DROP 字符后必须出现在 out_plain（去掉 DROP）中
# 反句：产出中长度 ≥30 的句子去掉 DROP 后必须出现在 src_plain 中
```

## 七、已知边界（交付时须向用户说明）

| 边界 | 说明 |
|------|------|
| **页内锚点不可用** | OneNote 没有 HTML 那种锚点 / 书签对象。目录条目**不是**可点击的页内跳转，导入后仍是普通文字。若用户要求目录可跳转，须改用"一节一页 + `[[页面名]]` 页面链接"方案，代价是拆页 |
| 不支持 `[[ ]]` 双向链接 | 本格式为**单页**方案，不做页面互链 |
| 粘贴建议 | 在 OneNote 中粘贴时选择「保留源格式」；表格与底色可完整保留 |
| 网页版仍可阅读 | OneNote 版同时是合法网页，可直接双击在浏览器中阅读、打印（已设 A4 页边距） |
| 转换器不负责内容 | `to_onenote.py` 只做格式转换，不改写、不增删任何正文内容 |
